## গল্প

করিম ভাই চান হিসাব করতে — মোট কত টাকার পণ্য বিক্রি হলো, কতজন ক্রেতা এলো তুলনা করতে।

## কোড

```python
price = 1500
quantity = 3

# গাণিতিক অপারেটর
total = price * quantity
print("মোট দাম:", total)
print("যোগফল:", 10 + 5)
print("বিয়োগফল:", 10 - 5)
print("ভাগফল:", 10 / 3)
print("ভাগশেষ:", 10 % 3)
print("পাওয়ার:", 2 ** 3)

# তুলনামূলক অপারেটর
print(price > 1000)   # True
print(price == 1500)  # True

# লজিক্যাল অপারেটর
has_discount = True
is_member = False
print(has_discount and is_member)   # False
print(has_discount or is_member)    # True
```

## অপারেটর এক নজরে

| ধরন | অপারেটর | কাজ |
| --- | --- | --- |
| গাণিতিক | `+  -  *  /  %  **` | যোগ, বিয়োগ, গুণ, ভাগ, ভাগশেষ, পাওয়ার |
| তুলনামূলক | `>  <  >=  <=  ==  !=` | মিলিয়ে `True` বা `False` দেয় |
| লজিক্যাল | `and  or  not` | একাধিক শর্ত জোড়া দেয় |

> `/` সবসময় `float` দেয় (`10 / 3` → `3.333…`)। পূর্ণসংখ্যার ভাগ চাইলে `//` ব্যবহার করো — `10 // 3` → `3`।
