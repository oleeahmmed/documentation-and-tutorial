## গল্প

করিম ভাই চান প্রতিদিনের বিক্রির হিসাব একটা ফাইলে স্থায়ীভাবে লিখে রাখতে।

## কোড

```python
# ফাইলে লেখা
with open("sales.txt", "w", encoding="utf-8") as f:
    f.write("আজকের বিক্রি: ১৫০০০ টাকা\n")
    f.write("মোট ক্রেতা: ১২ জন\n")

# ফাইল থেকে পড়া
with open("sales.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
```

## বাস্তব আউটপুট

```text
আজকের বিক্রি: ১৫০০০ টাকা
মোট ক্রেতা: ১২ জন
```

## মোড ও অংশ

| অংশ | কাজ |
| --- | --- |
| `"w"` | নতুন করে লেখে (আগের সব মুছে যায়) |
| `"r"` | পড়ে |
| `"a"` | শেষে যোগ করে (আগেরটা থাকে) |
| `encoding="utf-8"` | বাংলা লেখা ঠিকভাবে রাখে |
| `f.write("...\n")` | ফাইলে লেখে, `\n` নতুন লাইনে যায় |

`with` ব্যবহার করলে ফাইলটা কাজ শেষে নিজে থেকেই বন্ধ হয়ে যায় — আলাদা করে `f.close()` লিখতে হয় না।

> রিপোর্ট ফাইল বারবার যোগ করতে চাইলে `"w"`-এর বদলে `"a"` মোড ব্যবহার করো।
