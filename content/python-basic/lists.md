## গল্প

রফিক একটা তালিকা রাখতে চান — আজ কোন কোন পণ্য বাজারে দেখেছেন।

## কোড

```python
products = ["উলের ওভারকোট", "চাদর", "মাফলার"]

print(products)
print(products[0])          # প্রথম আইটেম
print(products[-1])         # শেষ আইটেম
print(len(products))        # মোট কতগুলো

products.append("সোয়েটার")  # নতুন যোগ করা
print(products)

products.remove("চাদর")     # বাদ দেওয়া
print(products)

# লিস্ট ঘুরে দেখা
for item in products:
    print("পণ্য:", item)
```

## দরকারি কাজ

| লিখা | কাজ |
| --- | --- |
| `products[0]` | প্রথম আইটেম |
| `products[-1]` | শেষ আইটেম |
| `len(products)` | মোট কতগুলো |
| `products.append(x)` | শেষে নতুন আইটেম যোগ |
| `products.remove(x)` | নির্দিষ্ট আইটেম বাদ |
| `for item in products:` | প্রতিটা আইটেম ঘুরে দেখা |

> লিস্ট পরিবর্তনযোগ্য — একবার বানানোর পরেও যোগ, বাদ বা বদল করা যায়।
