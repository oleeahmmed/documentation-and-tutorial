## গল্প

করিম ভাই তার দোকানের কিছু তথ্য মনে রাখতে চাইলেন — দোকানের নাম, আজকের বিক্রি, ক্রেতা আছে কিনা। প্রতিটা তথ্যের জন্য একটা "বাক্স" দরকার, যার একটা নাম থাকবে — এটাই Variable।

## কোড

```python
shop_name = "রূপসী ফ্যাশন"      # স্ট্রিং (text)
total_sales = 15000              # ইন্টিজার (পূর্ণ সংখ্যা)
average_price = 1250.50          # ফ্লোট (দশমিক সংখ্যা)
is_open = True                   # বুলিয়ান (True/False)

print(shop_name)
print(total_sales)
print(average_price)
print(is_open)

# কোন টাইপ, সেটা চেক করা
print(type(shop_name))
print(type(total_sales))
```

## বাস্তব আউটপুট

```text
রূপসী ফ্যাশন
15000
1250.5
True
<class 'str'>
<class 'int'>
```

## টাইপ এক নজরে

| টাইপ | উদাহরণ | কখন ব্যবহার |
| --- | --- | --- |
| `str` | `"রূপসী ফ্যাশন"` | নাম, ঠিকানা, লেখা |
| `int` | `15000` | পূর্ণ সংখ্যা — বিক্রি, স্টক |
| `float` | `1250.50` | দশমিক সংখ্যা — দাম, হার |
| `bool` | `True` / `False` | হ্যাঁ/না অবস্থা |

> `type()` দিয়ে যেকোনো সময় চেক করতে পারো। পরে CrewAI-তে `Agent(role="...", max_iter=5)` লিখলে — প্যারামিটারগুলোও ঠিক এই টাইপেরই।
