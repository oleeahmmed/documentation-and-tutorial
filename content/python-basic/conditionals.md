## গল্প

করিম ভাই চান — কোনো কাস্টমার ৫০০০ টাকার বেশি কিনলে ছাড় দেবেন, নাহলে না।

## কোড

```python
purchase_amount = 6000

if purchase_amount > 5000:
    print("আপনি ১০% ছাড় পাবেন!")
elif purchase_amount > 2000:
    print("আপনি ৫% ছাড় পাবেন!")
else:
    print("এখনো কোনো ছাড় নেই।")
```

## বাস্তব আউটপুট

```text
আপনি ১০% ছাড় পাবেন!
```

`purchase_amount` যদি `3000` হতো, তাহলে আউটপুট হতো `"আপনি ৫% ছাড় পাবেন!"` — আর `1000` হলে `"এখনো কোনো ছাড় নেই।"`

## কীভাবে কাজ করে

| অংশ | কাজ |
| --- | --- |
| `if` | প্রথম শর্ত সত্য হলে এই ব্লক চলে |
| `elif` | আগের শর্ত মিথ্যা হলে পরের শর্ত দেখে |
| `else` | কোনো শর্তই মিললে না গেলে এই ব্লক চলে |

> শর্তের পরে `:` দিতে হয়, আর ভেতরের লাইন অবশ্যই ইনডেন্ট (৪ স্পেস) করতে হয়।
