## গল্প

সুমন চান ৩টা ডিজাইনের প্রতিটার জন্য একটা একটা করে মেসেজ দেখাতে, আর করিম ভাই চান যতক্ষণ না স্টক শেষ হয়, ততক্ষণ বিক্রি চালিয়ে যেতে।

## কোড — for loop

```python
designs = ["ওভারকোট", "শাল", "চাদর"]

for i, design in enumerate(designs, start=1):
    print(f"{i}. {design} ডিজাইন তৈরি হচ্ছে")

# সংখ্যার রেঞ্জ নিয়ে
for number in range(1, 6):
    print("সংখ্যা:", number)
```

## কোড — while loop

```python
stock = 5

while stock > 0:
    print(f"স্টক আছে: {stock} পিস, একটা বিক্রি হলো")
    stock -= 1

print("স্টক শেষ!")
```

## কোনটা কখন

| লুপ | কখন ব্যবহার |
| --- | --- |
| `for` | তালিকা বা নির্দিষ্ট সংখ্যক বার ঘুরতে |
| `while` | শর্ত সত্য থাকা পর্যন্ত চলতে |

> `range(1, 6)` মানে ১ থেকে শুরু, ৬-এর আগে থামবে — তাই ১, ২, ৩, ৪, ৫। `enumerate(..., start=1)` লিস্টের সাথে ১ থেকে নম্বর দেয়।
