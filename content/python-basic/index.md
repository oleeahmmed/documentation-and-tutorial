করিম ভাই ঠিক করলেন তিনি নিজেই একটু প্রোগ্রামিং শিখবেন, যাতে পরে CrewAI দিয়ে কাজ করার সময় কোডটা অন্তত বুঝতে পারেন। তিনি একটা পাইথন ফাইল খুললেন আর একদম শুরু থেকে শিখতে বসলেন — তার দোকানের হিসাব-নিকাশ দিয়েই প্র্যাকটিস করবেন ঠিক করলেন।

**ইনস্টলেশন:** [Installation](/python-basic/installation) পেজে Python ইনস্টল করে venv বানিয়ে নাও, তারপর যেকোনো টেক্সট এডিটরে (VS Code) `.py` ফাইল বানিয়ে কাজ শুরু করো।

## অধ্যায়গুলো

প্রতিটা অধ্যায় আলাদা পেজ — গল্প, কোড, আর হুবহু আউটপুট সহ।

| অধ্যায় | কী শিখবে |
| --- | --- |
| [Variables ও Data Types](/python-basic/variables-data-types) | তথ্য মনে রাখার বাক্স — স্ট্রিং, ইন্টিজার, ফ্লোট, বুলিয়ান |
| [Operators](/python-basic/operators) | হিসাব-নিকাশ, তুলনা আর লজিক্যাল অপারেটর |
| [Strings](/python-basic/strings) | লেখা নিয়ে কাজ — f-string, strip, split |
| [Conditionals](/python-basic/conditionals) | সিদ্ধান্ত নেওয়া — if / elif / else |
| [Lists](/python-basic/lists) | একাধিক জিনিসের তালিকা — যোগ, বাদ, ঘুরে দেখা |
| [Loops](/python-basic/loops) | বারবার একই কাজ — for ও while |
| [Tuples ও Sets](/python-basic/tuples-sets) | অপরিবর্তনীয় তথ্য আর ইউনিক তালিকা |
| [Dictionaries](/python-basic/dictionaries) | নাম আর মান জোড়া করে রাখা |
| [Functions](/python-basic/functions) | একবার লেখা, বারবার ব্যবহারযোগ্য নিয়ম |
| [Error Handling](/python-basic/error-handling) | ভুল হলেও প্রোগ্রাম যেন না থামে — try / except |
| [File Handling](/python-basic/file-handling) | ফাইলে লেখা আর ফাইল থেকে পড়া |
| [Classes ও Objects](/python-basic/classes-objects) | বাস্তব জিনিসকে কোডে রূপ দেওয়া (OOP) |
| [Modules ও Imports](/python-basic/modules-imports) | কোড আলাদা ফাইলে গুছিয়ে রাখা |
