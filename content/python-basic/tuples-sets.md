## গল্প

করিম ভাই চান কিছু তথ্য যেন **কখনো বদলানো না যায়** (যেমন দোকানের প্রতিষ্ঠার তারিখ) — এটার জন্য Tuple। আর চান ডুপ্লিকেট ছাড়া শুধু আলাদা আলাদা রঙের তালিকা — এটার জন্য Set।

## কোড

```python
# Tuple — পরিবর্তন করা যায় না
shop_info = ("রূপসী ফ্যাশন", 2015)
print(shop_info[0], "প্রতিষ্ঠিত হয়েছিল", shop_info[1], "সালে")

# Set — ডুপ্লিকেট বাদ হয়ে যায় নিজে থেকেই
colors = {"লাল", "নীল", "লাল", "সবুজ"}
print(colors)
```

## বাস্তব আউটপুট

```text
রূপসী ফ্যাশন প্রতিষ্ঠিত হয়েছিল 2015 সালে
{'লাল', 'নীল', 'সবুজ'}
```

## পার্থক্য

| | Tuple | Set |
| --- | --- | --- |
| ব্র্যাকেট | `(...)` | `{...}` |
| পরিবর্তন | করা যায় না | যোগ/বাদ করা যায় |
| ডুপ্লিকেট | থাকতে পারে | নিজে থেকেই বাদ যায় |
| ক্রম | যেভাবে লিখবে সেভাবেই থাকে | নির্দিষ্ট ক্রম নেই |

> Set-এর আউটপুটের ক্রম Python সংস্করণ অনুযায়ী আলাদা দেখাতে পারে — উপরের ক্রমটা নিশ্চিত ধরে নিও না, শুধু ডুপ্লিকেট বাদ পড়াটাই নিশ্চিত।
