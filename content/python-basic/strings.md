## গল্প

নাদিয়া চান কাস্টমারের নাম দিয়ে একটা সুন্দর বার্তা বানাতে — "প্রিয় রহিম, আপনাকে ধন্যবাদ।"

## কোড

```python
customer_name = "রহিম"
message = f"প্রিয় {customer_name}, আপনাকে ধন্যবাদ।"
print(message)

# স্ট্রিং-এর কিছু কাজ
text = "  রূপসী ফ্যাশন  "
print(text.strip())           # দুই পাশের স্পেস বাদ
print(text.upper())           # বড় হাতের অক্ষর
print(len("রূপসী"))           # দৈর্ঘ্য
print("ফ্যাশন" in text)       # শব্দটা আছে কিনা
print("উলের ওভারকোট, চাদর, মাফলার".split(","))   # ভাগ করা
```

## বাস্তব আউটপুট

```text
প্রিয় রহিম, আপনাকে ধন্যবাদ।
রূপসী ফ্যাশন
  রূপসী ফ্যাশন  
5
True
['উলের ওভারকোট', ' চাদর', ' মাফলার']
```

## দরকারি মেথড

| লিখা | কাজ |
| --- | --- |
| `f"প্রিয় {name}"` | ভ্যারিয়েবল বসিয়ে লেখা (f-string) |
| `text.strip()` | দুই পাশের স্পেস বাদ দেয় |
| `text.upper()` | বড় হাতের অক্ষর করে |
| `text.split(",")` | নির্দিষ্ট চিহ্নে ভাগ করে লিস্ট বানায় |
| `len(text)` | কত অক্ষর, তা গোনে |
| `"শব্দ" in text` | ভেতরে আছে কিনা `True`/`False` দেয় |

> বাংলা অক্ষরের ছোট-বড় হাতের রূপ নেই, তাই `.upper()` বাংলা লেখায় দেখতে একই থাকে — এটা ভুল নয়।
