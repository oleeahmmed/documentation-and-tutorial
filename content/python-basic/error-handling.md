## গল্প

নাদিয়া কাস্টমারের দেওয়া সংখ্যা দিয়ে হিসাব করেন, কিন্তু মাঝে মাঝে কাস্টমার ভুল করে সংখ্যার বদলে অক্ষর লিখে ফেলেন। করিম ভাই চান প্রোগ্রাম যেন ক্র্যাশ না করে, বরং একটা ভদ্র বার্তা দেখায়।

## কোড

```python
def get_price_safely(value):
    try:
        price = int(value)
        return price
    except ValueError:
        print("ভুল ইনপুট! সংখ্যা দিতে হবে।")
        return None

print(get_price_safely("1500"))
print(get_price_safely("পাঁচশো"))
```

## বাস্তব আউটপুট

```text
1500
ভুল ইনপুট! সংখ্যা দিতে হবে।
None
```

## অংশগুলো

| অংশ | কাজ |
| --- | --- |
| `try:` | যেখানে ভুল হতে পারে, সেই কোড |
| `except ValueError:` | নির্দিষ্ট ভুল হলে কী করতে হবে |
| `return None` | ভুল হলে খালি ফলাফল ফেরত দেয় |

## সাধারণ কিছু ভুল

| ভুল | কখন হয় |
| --- | --- |
| `ValueError` | সংখ্যার জায়গায় অক্ষর (`int("পাঁচশো")`) |
| `TypeError` | ভুল টাইপ মিলিয়ে কাজ (সংখ্যা + লেখা) |
| `FileNotFoundError` | যে ফাইল খুঁজছ, সেটা নেই |
| `KeyError` | Dictionary-তে যে key খুঁজছ, সেটা নেই |

> `except`-এ নির্দিষ্ট ভুলের নাম লেখা ভালো অভ্যাস — সব ভুল একসাথে গিলে ফেললে আসল সমস্যাটা চাপা পড়ে যায়।
