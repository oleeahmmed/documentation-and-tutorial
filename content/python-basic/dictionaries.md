## গল্প

নাদিয়া চান প্রতিটা পণ্যের সাথে তার দাম জুড়ে রাখতে — শুধু একটা তালিকা না, নাম আর দাম একসাথে।

## কোড

```python
price_list = {
    "উলের ওভারকোট": 1800,
    "চাদর": 900,
    "মাফলার": 350
}

print(price_list["চাদর"])            # নির্দিষ্ট দাম বের করা
price_list["সোয়েটার"] = 1200          # নতুন যোগ করা

for item, price in price_list.items():
    print(f"{item}: {price} টাকা")

print("উলের ওভারকোট" in price_list)   # আছে কিনা চেক
```

## বাস্তব আউটপুট

```text
900
উলের ওভারকোট: 1800 টাকা
চাদর: 900 টাকা
মাফলার: 350 টাকা
সোয়েটার: 1200 টাকা
True
```

## দরকারি কাজ

| লিখা | কাজ |
| --- | --- |
| `price_list["চাদর"]` | নির্দিষ্ট key-এর মান |
| `price_list["সোয়েটার"] = 1200` | নতুন key-value যোগ বা বদল |
| `price_list.items()` | সব key-value জোড়া ঘুরে দেখা |
| `"চাদর" in price_list` | key আছে কিনা `True`/`False` |

> Dictionary-র key সাধারণত লেখা (string) বা সংখ্যা হয়। বুঝতে সুবিধা — বন্ধনীর ভেতরে প্রতিটা জিনিসের একটা নাম আর একটা মান।
