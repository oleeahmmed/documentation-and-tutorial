## গল্পটা এক নজরে

- গ্রাহক ঢুকলেন, হাতে ধরিয়ে দেওয়া হলো **অর্ডার স্লিপ** (State)
- গেটম্যান স্লিপে লিখল "এ কিনতে চায়", আর **রাস্তা বাছল** (conditional edge)
- স্টকম্যান স্লিপ পড়ে লিখল "মাল আছে", তারপর ক্যাশিয়ার স্লিপ পড়ে অর্ডার নিশ্চিত করল (edge)
- মাল না থাকলে স্লিপ **ঘুরে এল** আবার স্টক দেখতে (loop)
- গ্রাহকের নামে একটা **খাতা** রাখা হলো, যাতে পরের বার আগের কথা মনে থাকে (checkpointer)
- বড় অর্ডারে স্লিপ **থেমে গেল** রফিক সাহেবের সইয়ের জন্য (interrupt)
- শেষে গেটম্যানের জায়গায় বসল **AI** — যা খুশি ভাবে লেখা হলেও উদ্দেশ্য বোঝে (LLM node)

## কোন জিনিস কোন ধাপে

| জিনিস | ধাপ | এক লাইনে |
| --- | --- | --- |
| State | ২ | সবাই যে স্লিপ পড়ে-লেখে |
| Node | ২ | এক কাজের ফাংশন, আংশিক update ফেরত দেয় |
| Edge | ৩ | "এরপর ওর কাছে যাও" |
| Conditional edge | ৪ | state দেখে রাস্তা বাছা |
| Loop | ৬ | আগের node-এ ফেরত যাওয়া edge + থামার শর্ত |
| Checkpointer | ৭ | গ্রাহকের খাতা, `thread_id` দিয়ে আলাদা |
| interrupt | ৮ | মাঝপথে থেমে মানুষের সই নেওয়া |
| LLM node | ৯ | এক node-এর ভেতর বদলে AI বসানো |

## সাধারণ ভুল

1. **রাউটারের ফেরত দেওয়া শব্দ ম্যাপিংয়ে নেই** — ম্যাপিং ডিকশনারিতে সব সম্ভাব্য শব্দ লিখো
2. **State-এ নেই এমন ঘরের নাম ফেরত দেওয়া** — আগে State ক্লাসে ঘরটা ঘোষণা করো
3. **চেকপয়েন্টার ছাড়া `interrupt`** — এরর আসবে, কারণ থেমে থাকা অবস্থা রাখার জায়গা নেই
4. **লুপে থামার শর্ত না রাখা** — `GraphRecursionError` আসবে
5. **node থেকে পুরো স্লিপ ফেরত দেওয়া** — শুধু বদলানো ঘর ফেরত দাও

## নিজে করে দেখো

1. **সহজ** — `classify_intent`-এ "ফেরত" শব্দ পেলে আলাদা `return_request` উদ্দেশ্য বানাও, আর নতুন node-এ বলো "অর্ডার নম্বর দিন"
2. **মাঝারি** — অর্ডারের দাম ৫০০০ টাকার বেশি হলে একটা `discount` node-এ ১০% ছাড় দাও, তারপর `confirm_order`-এ যাও
3. **কঠিন** — স্টক ৩-এর কম হলে রফিক সাহেবকে সতর্কবার্তা পাঠাও (শুরুতে `print` দিয়েই করো)
4. **বস লেভেল** — ধাপ ৪, ৬, ৭, ৮ এক গ্রাফে জুড়ে দাও

## CrewAI আর LangGraph, এক নজরে

| | CrewAI | LangGraph |
| --- | --- | --- |
| তথ্য পাঠানো | `context=[task]` দিয়ে | সবাই একই State পড়ে-লেখে |
| কাজের ক্রম | `Process.sequential` | নিজের হাতে ফ্লোচার্ট আঁকো |
| রাস্তা ভাগ | সীমিত | `add_conditional_edges` |
| লুপ | কঠিন | একটা edge দিলেই হয় |
| মানুষের অনুমতি | আলাদা ব্যবস্থা | `interrupt` |

যেখানে ধাপ নির্দিষ্ট আর নিয়ম কড়া, সেখানে LangGraph ভালো। যেখানে এজেন্টদের স্বাধীনতা দিয়ে দল বানাতে চাও, সেখানে [CrewAI](/docs) ভালো।
