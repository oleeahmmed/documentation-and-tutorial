## গল্প

রফিক সাহেব কাগজে দোকানের নকশা এঁকে দেয়ালে টাঙালেন। কর্মচারীরা দেখে বুঝলেন, কে কার পরে, কোন রাস্তা কোথায় গেছে।

তোমার গ্রাফেরও ছবি আছে — এক লাইন কোডেই।

## কোড

`ruposhi.py`-র একদম শেষে এই লাইনটা যোগ করো:

```python
# গ্রাফটাকে mermaid নামের একটা চিত্র-ভাষায় ছাপাবে
print(graph.get_graph().draw_mermaid())
```

চালাও:

```bash
python ruposhi.py
```

## বাস্তবে কী ঘটে

আউটপুটে `graph TD;` দিয়ে শুরু একটা লেখা আসবে — ভেতরে প্রতিটা node আর রাস্তা। চেহারা হবে এরকম:

```text
graph TD;
    __start__([__start__]):::first
    classify_intent(classify_intent)
    check_stock(check_stock)
    ...
    __end__([__end__]):::last
    __start__ --> classify_intent;
    classify_intent -.-> give_price;
    classify_intent -.-> check_stock;
    ...
```

- `-->` মানে সাধারণ edge
- `-.->` মানে conditional edge (শর্তসাপেক্ষ রাস্তা)

পুরো লেখাটা কপি করে [mermaid.live](https://mermaid.live)-এ পেস্ট করো — সাথে সাথে ছবি হয়ে যাবে।

## ছবিতে কী দেখবে

| দেখো | কেন |
| --- | --- |
| `classify_intent` থেকে চারটা বেরোনো রাস্তা | চারটা intent-এর ম্যাপিং ঠিক আছে কি না |
| `check_stock` → `confirm_order` | অর্ডারের মিছিল ঠিক আছে কি না |
| প্রতিটা শেষ node `__end__`-এ মিশেছে | কোনো রাস্তা ঝুলে আছে কি না |

## মনে রাখো

- ছবি দেখার কাজ শুধু সাজানো নয় — **ভুল রাস্তা চোখে ধরা পড়ে**। যেমন ভুল করে `give_price` থেকে `END`-এর edge ভুলে গেলে ছবিতে ওই রাস্তা ঝুলে থাকবে
- কোনো প্যাকেজ আলাদা করে ইনস্টল করতে হয় না — `draw_mermaid()` LangGraph-এর ভেতরেই আছে

## সমস্যা হলে

| সমস্যা | সমাধান |
| --- | --- |
| mermaid.live-এ ছবি আসছে না | পুরো আউটপুট কপি করেছ তো? প্রথম লাইন `graph TD;` সহ |
| node-এর নাম এলোমেলো | ঠিক আছে — ছবির সাজানো নিয়ম আলাদা, রাস্তা ঠিক থাকাটাই আসল |
