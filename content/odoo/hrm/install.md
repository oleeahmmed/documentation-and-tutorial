## গল্প

মালিক হিসেবে এটা তোমার সবচেয়ে বড় সিদ্ধান্ত: Odoo কোথায় চলবে? দুইটা পথ — **Odoo Online** (সবচেয়ে সহজ, সাবস্ক্রিপশন) আর **নিজের সার্ভারে Community** (ফ্রি, কিন্তু IT লাগবে)। দুটোই কাজ করবে; পার্থক্য শুধু খরচ, কন্ট্রোল আর Enterprise অ্যাপে।

## Option A — Odoo Online (সবচেয়ে সহজ)

1. `odoo.com`-এ গিয়ে **Try free** দাও
2. কোম্পানির নাম দাও (`Rahim Apparels Ltd.`), একটা অ্যাডমিন ইমেইল দাও
3. কিছু ইনস্টল করতে হবে না — সরাসরি ব্রাউজারে চলবে

Enterprise ফিচার (Appraisals ইত্যাদি) এখানে পাবে। শুরু করার জন্য এটাই সবচেয়ে কম ঝামেলার পথ।

## Option B — নিজের সার্ভারে (Community)

একজন IT লোক দিয়ে Ubuntu সার্ভারে বসাও। Docker থাকলে মোটামুটি এভাবে:

```bash
docker run -d -e POSTGRES_USER=odoo -e POSTGRES_PASSWORD=odoo -e POSTGRES_DB=postgres --name db postgres:15
docker run -p 8069:8069 --name odoo --link db:db -t odoo:17
```

> **ভার্সন:** উপরের উদাহরণটা ১৭ (ডকুমেন্টের মতোই)। Odoo 19 চাইলে শুধু শেষ লাইনে `odoo:17`-এর জায়গায় `odoo:19` দাও — বাকি ধাপ একই। প্রোডাকশনে পিন করা একটা ভার্সনই রাখো, মাঝেমধ্যে বদলাবে না।

Docker ছাড়া Ubuntu-তে সোর্স থেকে ইনস্টল করার পুরো নিয়ম (Python, PostgreSQL, venv, `odoo.conf`, systemd) আলাদা সেকশনে আছে — [Installation](/odoo/installation) দেখে নাও।

## ডাটাবেস তৈরি

ব্রাউজারে `http://সার্ভার-IP:8069` (Docker হলে) অথবা `http://localhost:8069` খোলো → **Create Database**:

| ফিল্ড | মান |
| --- | --- |
| Database Name | `rahim_apparels` |
| Email | তোমার অ্যাডমিন ইমেইল |
| Password | শক্ত পাসওয়ার্ড (মালিকেরটা) |
| Phone Number | (ঐচ্ছিক) |
| Language | **English** (পরে বাংলা যোগ করা যাবে) |
| Country | **Bangladesh** |
| Demo Data | ✗ (টিক দিও না) |

**Demo Data বন্ধ রাখা কেন?** ডেমো ডেটা থাকলে ভুয়া কর্মী, ভুয়া Department, ভুয়া ছুটির হিসাব ঢুকে যাবে — পরে কোনটা আসল আর কোনটা ডেমো, আলাদা করা কষ্ট। খালি ডাটাবেস দিয়ে শুরু করলে সব তোমার নিজের ডেটা।

> **পাসওয়ার্ড:** মালিক হিসেবে তুমি শুধু এই "প্রথম অ্যাডমিন ইউজার" তৈরি করবে। এই পাসওয়ার্ড কারও সাথে শেয়ার করবে না, Git-এ বা ডকুমেন্টে লিখে রাখবে না।

## প্রথম লগইন

Create চাপলে Odoo সরাসরি ড্যাশবোর্ডে নিয়ে যাবে। উপরে বাঁদিকে **Apps** মেনু দেখতে পাবে — পরের ধাপে এখান থেকেই HR অ্যাপগুলো ইনস্টল করব।

## সমস্যা হলে

| সমস্যা | সমাধান |
| --- | --- |
| `http://localhost:8069` খুলছে না | `docker ps` দিয়ে দুটো কন্টেইনার চলছে কিনা দেখো; পোর্ট 8069 অন্য কিছু নিয়েছে কিনা চেক করো |
| ডাটাবেস তৈরি পেজ আসছে না | পুরোনো ডাটাবেস থাকলে Odoo সেটাই খোলে — `/web/database/manager`-এ গিয়ে নতুন ডাটাবেস বানাও |
| Odoo 19 image পাচ্ছি না | `docker pull odoo:19` দিয়ে আগে টেনে নাও, তারপর চালাও |
| ডেমো ডেটা ভুলে টিক দিয়েছি | নতুন ডাটাবেস বানানোই সহজ — পুরোনোটা ডিলিট করে আবার Create |
