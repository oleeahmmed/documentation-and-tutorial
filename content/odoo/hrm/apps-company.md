## গল্প

ফ্যাক্টরি চালু, মালিক Odoo-তে ঢুকবেন। প্রথম দিনের কাজগুলো একবারের — লগইন, অ্যাপ ইনস্টল, ডেভেলপার মোড, কোম্পানির নাম-ঠিকানা-টাকার একক। এই ভিত্তিটা ঠিক থাকলে বাকি সব অ্যাপ সঠিকভাবে কাজ করবে।

## ১.১ — Login

1. Browser-এ Odoo লিংক খোলো — `https://তোমার-নাম.odoo.com` অথবা `http://সার্ভার-IP:8069`
2. Admin Email আর Password দিয়ে **Log in**

> পাসওয়ার্ড ভুলে গেলে সার্ভারে Odoo-র ডাটাবেস ম্যানেজার থেকে admin পাসওয়ার্ড রিসেট করা যায় ([Database](/odoo/configuration/database) পেজে দেখো)। Odoo Online-এ ফরগট পাসওয়ার্ড লিংক ব্যবহার করো।

## ১.২ — Apps Install

উপরে বাঁ দিকে অ্যাপ আইকন → **Apps** → সার্চ বক্সে নাম লিখে **Install**। একটা একটা করে:

| সার্চ করো | ইনস্টল |
| --- | --- |
| Employees | হ্যাঁ |
| Recruitment | হ্যাঁ |
| Time Off | হ্যাঁ |
| Attendances | হ্যাঁ |
| Appraisals | হ্যাঁ (Enterprise হলে) |
| Expenses | হ্যাঁ |
| Fleet | হ্যাঁ |
| Maintenance | হ্যাঁ |
| Lunch | হ্যাঁ (ক্যান্টিন থাকলে) |

শেষে হোম স্ক্রিনে সব আইকন দেখা গেলে ঠিক আছে।

> কিছু অ্যাপ একে অন্যের উপর নির্ভর করে — যেমন Time Off আর Attendances ইনস্টল করলে Employees নিজে থেকেই ইনস্টল হয়ে যায়। তাই লিস্টের ক্রম নিয়ে চিন্তা নেই, শুধু শেষে সবগুলো আছে কিনা দেখো।

## ১.৩ — Developer Mode চালু করো

**Settings** → একদম নিচে স্ক্রল → **Activate the developer mode**।

> কেন লাগবে? কিছু মেনু (যেমন Working Schedules-এর পুরোনো পথ, Technical Menu) শুধু Developer Mode-এ দেখা যায়। কাজ শেষে Settings-এর একই জায়গা থেকে বন্ধ করে দিতে পারো — বন্ধ করলে সাধারণ ব্যবহারকারীর স্ক্রিন পরিষ্কার থাকে।

## ১.৪ — কোম্পানির তথ্য

**Settings → General Settings → Companies → Update Info**

| ফিল্ড | মান |
| --- | --- |
| Company Name | `Rahim Apparels Ltd.` |
| ঠিকানা | ফ্যাক্টরির আসল ঠিকানা |
| ফোন, ইমেইল | অফিসের নম্বর ও ইমেইল |
| লোগো | কোম্পানির লোগো (ইনভয়েস, Payslip, রিপোর্টে দেখাবে) |
| Currency | **BDT** |

তারপর **Save**।

> Currency ভুল থাকলে পরে সব অ্যাপে টাকার হিসাব ভুল দেখাবে। BDT বাছার পর টাকার প্রতীক আর দশমিকের ঘর একবার চেক করে নাও।

## বাস্তবে কী ঘটে

- ৯টা অ্যাপ ইনস্টল হলে Employees একবারই বানাতে হবে — বাকি অ্যাপ (Time Off, Attendances, Expenses) ওই একই কর্মীর তথ্য ব্যবহার করে
- কোম্পানির লোগো ও ঠিকানা সব ডকুমেন্টে (রিপোর্ট, Payslip, চিঠি) স্বয়ংক্রিয়ভাবে বসে
- BDT সেট থাকলে সব টাকার ঘর `৳` দেখাবে; পরে বদলালে পুরোনো রেকর্ডের হিসাব বদলাবে না
- Developer Mode চালু থাকলে ফর্মের পাশে Technical দিক (View, Fields) দেখা যায় — সাধারণ কাজে দরকার নেই, ভুল করে কিছু বদলিয়ো না

## সমস্যা হলে

| সমস্যা | সমাধান |
| --- | --- |
| Apps-এ অ্যাপ খুঁজে পাচ্ছি না | Apps → **Update Apps List** (Developer Mode লাগতে পারে) |
| Install বাটন ধূসর | Admin হিসেবে লগইন করেছ কিনা দেখো |
| Appraisals খুঁজে পাচ্ছি না | Community ভার্সনে অ্যাপটা নেই; Enterprise/Online লাগবে |
| ইনস্টল শেষ হচ্ছে না | ইন্টারনেট/সার্ভার লোড দেখো, Odoo লগে error আছে কিনা চেক করো |
| Currency-তে BDT নেই | তালিকায় **BDT** সার্চ করো; না পেলে Currencies-এ Active করো ([Currency](/odoo/configuration/currency)) |
