## গল্প

ফ্যাক্টরির পাশে ক্যান্টিন — কর্মী ৳৬০-এ ভাত-ডাল-মুরগি খায়, কোম্পানি বাকিটা ভর্তুকি দেয়। কে খাবে না, কত প্লেট লাগবে — রোজ সকালে হিসাব রাখতে হয়। Lunch অ্যাপে কর্মী নিজেই অর্ডার করবে, ক্যান্টিন মোট সংখ্যা দেখে খাবার বানাবে।

> ক্যান্টিন না থাকলে এই ধাপটা বাদ দাও — অন্য ধাপে কোনো প্রভাব পড়বে না।

## ১৩.১ — Vendor ও Product

**Lunch → Configuration → Vendors → New**

- Vendor Name, ফোন, ঠিকানা
- ক্যান্টিনের সাথে চুক্তি থাকলে নোটে

**Lunch → Configuration → Products → New**

| Product | দাম (উদাহরণ) |
| --- | --- |
| ভাত-ডাল-মুরগি | ৳60 |
| খিচুড়ি | ৳45 |
| শুধু ভাত-তরকারি | ৳35 |

প্রতিটা Product-এ Vendor আর Category বসাও। Product Categories (যেমন `দুপুরের খাবার`) আলাদা করে বানাতে পারো।

## ১৩.২ — কর্মীর অর্ডার

1. কর্মী **Lunch → My Lunch → New Order** খুলবে
2. তারিখ, Product, পরিমাণ বেছে নেবে
3. অর্ডার দিলে টাকা তার Lunch অ্যাকাউন্টের ব্যালেন্স থেকে কাটবে
4. নিজের খরচ ও ব্যালেন্স দেখবে **Lunch → My Lunch → My Account History**-তে

ব্যালেন্স শেষ হলে অর্ডার হবে না — করিম স্যার আগেই টপ-আপ করে দেবেন (১৩.৩)।

## ১৩.৩ — ক্যান্টিনের হিসাব

- করিম স্যার **Lunch → Manager → Today's Orders** থেকে আজকের মোট অর্ডার সংখ্যা বের করে ক্যান্টিনকে জানাবেন
- Vendor-ভিত্তিক খরচ **Lunch → Manager → Control Vendors**-এ
- কার ব্যালেন্স কত — **Manager → Control Accounts**; টপ-আপ দিতে **Manager → Cash Moves → New** → User বাছো, Amount পজিটিভ (যেমন `1000`), Description `November top-up`
- Alert বানিয়ে দিতে পারো: **Lunch → Configuration → Alerts** → `Order by 11:00 AM` — দেরিতে অর্ডার করলে আর খাবার মিলবে না, এটা কর্মীদের অ্যাপে দেখাবে

## বাস্তবে কী ঘটে

- অর্ডার করা মাত্র ক্যান্টিনের তালিকায় যোগ হয়; বাতিল করলে বাদ যায়
- ব্যালেন্স শেষ হলে অর্ডার বন্ধ — টপ-আপ হলে আবার চালু
- একই দিনে একাধিক অর্ডার দিলে সব যোগ হয়, তাই কর্মীকে বলে দাও একবারেই দিতে
- Month-end রিপোর্টে কে কতবার খেয়েছে, কত টাকা ভর্তুকি গেল — সব পাওয়া যায়
