## গল্প

কোম্পানির দুইটা হায়েস, একটা পিকআপ, কয়েকটা মোটরসাইকেল। কোন গাড়ির ফিটনেস কবে শেষ, কে ড্রাইভার, তেল-সার্ভিসিংয়ে মাসে কত খরচ — এসব মনে রাখা যায় না। Fleet অ্যাপে গাড়ি যোগ করলে মেয়াদ শেষের আগেই রিমাইন্ডার আসবে।

## ১১.১ — গাড়ি যোগ করা

**Fleet → Fleet → Fleet** — এখানেই গাড়ির তালিকা। **New** চেপে গাড়ি বানাও:

| ফিল্ড | উদাহরণ |
| --- | --- |
| Model | Toyota Hiace |
| License Plate | বগুড়া-ল-১১-২৩৪৫ |
| Driver | ড্রাইভারের Employee রেকর্ড |
| Odometer | বর্তমান কিলোমিটার |
| Tags | `Delivery`, `Staff` |

Driver ফিল্ডে Employee ড্রপডাউন আসে — তাই ড্রাইভারকে আগে Employees-এ যোগ করতে হবে (ধাপ ৫)।

## ১১.২ — সার্ভিসিং (Services)

**Fleet → Fleet → Services → New** (গাড়ির ফর্মের **Services** স্মার্ট বাটন থেকেও)

- Service Type: `Oil Change`, `Tire`, `Repair`, `Insurance` ইত্যাদি
- Date, Cost, Vendor
- নোটে কী করা হলো লেখো

প্রতিটা সার্ভিসে খরচ বসালে গাড়িভিত্তিক মোট খরচ নিজে থেকেই হিসাব হয় — রিপোর্ট: **Fleet → Reporting → Costs**।

## ১১.৩ — Contracts (ইনসুরেন্স, ফিটনেস, ট্যাক্স টোকেন)

**Fleet → Fleet → Contracts** (গাড়ির ফর্মের **Contracts** স্মার্ট বাটনও একই)

| কন্ট্রাক্ট | মেয়াদ শেষের তারিখ |
| --- | --- |
| Insurance | পলিসি অনুযায়ী |
| Fitness | মেয়াদ শেষের তারিখ |
| Tax Token | মেয়াদ শেষের তারিখ |

- **Responsible** — যিনি মেয়াদ শেষের অ্যালার্ট পাবেন (করিম)
- **Expiration Date** বসলেই **End Date Contract Alert** অনুযায়ী আগেভাগে ইমেইল যাবে (Settings-এ কত দিন আগে, ঠিক করা যায়)

> **ফিটনেস/টোকেন মিস করলে:** গাড়ি রাস্তায় নামানো যাবে না, জরিমানা + ব্যবসার ক্ষতি। Expiration Date প্রতিটা কন্ট্রাক্টে অবশ্যই দাও, আর রিমাইন্ডার ইমেইলের জন্য Odoo-র outgoing mail সেটআপ থাকা লাগবে।

## ১১.৪ — জ্বালানি, ওডোমিটার ও খরচ

Odoo 19-এ আলাদা "Fuel Log" মেনু নেই — জ্বালানিও একটা সার্ভিস এন্ট্রি হিসেবেই রাখো।

1. আগে একটা সার্ভিস টাইপ বানাও: Developer Mode চালু করে **Fleet → Configuration → Services → Types → New** → নাম `Fuel`, Category `Service`
2. এরপর প্রতিবার তেল ভরালে **Fleet → Fleet → Services**-এ `Fuel` টাইপে তারিখ, খরচ, লিটার নোটে লিখে এন্ট্রি দাও
3. **Fleet → Fleet → Odometer**-এ কিলোমিটার আপডেট রাখো — প্রতি কিলোমিটারের খরচ হিসাব করা যায়
4. **Fleet → Reporting → Costs** থেকে প্রতি গাড়ির মোট ও মাসিক খরচ দেখো

> গাড়ির ফর্মে **Fuel Type** ফিল্ডটা জ্বালানির ধরন (Petrol/Diesel) — খরচের এন্ট্রি নয়। খরচ সবসময় Services বা Contracts-এ বসবে, তখনই Reporting → Costs-এ দেখা যাবে।

## বাস্তবে কী ঘটে

- Contract-এর মেয়াদ শেষের আগে Responsible-কে অ্যালার্ট যায়
- Driver হিসেবে Employee বাছলে তার প্রোফাইলেও গাড়ির লিংক থাকে
- এক গাড়ির সব সার্ভিস, কন্ট্রাক্ট, খরচ — এক ফর্মে স্মার্ট বাটন দিয়ে
- গাড়ি বিক্রি হলে Archive করো — রেকর্ড মুছবে না, তালিকায় শুধু দেখাবে না

## সমস্যা হলে

| সমস্যা | সমাধান |
| --- | --- |
| Driver ড্রপডাউনে নেই | Employee তৈরি করো, বা স্টাফ ড্রাইভার হলে User লিংক দাও |
| কন্ট্রাক্ট অ্যালার্ট আসছে না | Expiration Date আছে কি না, End Date Contract Alert-এর দিন ঠিক কি না, ইমেইল সেটআপ |
| Reporting → Costs দেখা যাচ্ছে না | এটা Fleet Manager-দের মেনু — ইউজারের Fleet অ্যাক্সেস লেভেল দেখো |
| জ্বালানি এন্ট্রি কোথায় | Services-এ `Fuel` টাইপ বানিয়ে এন্ট্রি দাও (১১.৪) |
| পুরোনো গাড়ি তালিকায় থেকে যাচ্ছে | Archive করো (Action → Archive) |
