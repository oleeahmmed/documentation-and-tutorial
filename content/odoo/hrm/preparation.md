## কেন আগে কাগজে

Odoo খুলে বসে ভাবতে শুরু করলে মাঝপথে আটকে যাবে — Department-এর নাম কী হবে, পদবি কয়টা, ছুটি কত দিন। তাই আগে একটা খাতায় বা Excel-এ সব ঠিক করে নাও। পরে এই তথ্যগুলোই Odoo-তে বসাব, আর কর্মীর তালিকা Excel থেকেই Import করব।

## যা যা রেডি করবে

1. কোম্পানির নাম, ঠিকানা, ফোন, লোগো
2. Department-এর তালিকা ও প্রধান কে
3. পদবির তালিকা (Operator, Sr. Operator, Line Chief, Supervisor, QC Inspector...)
4. কর্মীর তালিকা: নাম, ID নম্বর, ফোন, NID, যোগদানের তারিখ, department, পদ, বেতন
5. অফিস সময় (যেমন সকাল ৮টা–বিকাল ৫টা, ১ ঘণ্টা বিরতি)
6. সাপ্তাহিক ছুটি (শুক্রবার) ও বছরের সরকারি ছুটির তালিকা
7. ছুটির নিয়ম (নিচের টেবিল দেখে)

### Excel-এ কোন কলামগুলো রাখবে

কর্মীর তালিকাটা এই কলামগুলো দিয়ে বানাও — পরে Odoo-র Import-এ হুবহু এগুলোই লাগবে:

| কলাম | উদাহরণ | Odoo-তে যায় কোথায় |
| --- | --- | --- |
| Name | Rina Akter | Employee's Name |
| Identification No | NID নম্বর | HR Settings → Identification No |
| Department | Sewing | Work Information → Department |
| Job Position | Sewing Operator | Job Position |
| Work Mobile | 017XXXXXXXX | Work Mobile |
| Work Email | (থাকলে) | Work Email |
| Work Location | Factory Floor 2 | Work Information → Work Location |

> **নিরাপত্তা:** NID, ব্যাংক অ্যাকাউন্ট, বেতনের শিট — এগুলো সংবেদনশীল তথ্য। ফাইলটা পাসওয়ার্ড-প্রোটেক্টেড রাখো, শুধু HR Manager আর মালিকের কাছে থাকুক, হোয়াটসঅ্যাপে ছড়াবে না।

## বাংলাদেশ শ্রম আইন ২০০৬ অনুযায়ী সাধারণ নিয়ম

চূড়ান্ত করার আগে আপনার কোম্পানির আইনজীবী/কমপ্লায়েন্স অফিসারের সাথে মিলিয়ে নাও — নিয়ম সময়ে সময়ে সংশোধন হয়।

| ছুটি | দিন |
| --- | --- |
| নৈমিত্তিক (Casual) | ১০ দিন/বছর |
| অসুস্থতা (Sick) | ১৪ দিন/বছর |
| অর্জিত (Annual/Earned), কারখানায় | ১৮ দিন কাজে ১ দিন |
| উৎসব ছুটি | ১১ দিন/বছর |
| মাতৃত্বকালীন | মোট ১৬ সপ্তাহ (৮ আগে + ৮ পরে) |

এই সংখ্যাগুলোই পরে **Time Off** অ্যাপে বসাব — Casual ১০, Sick ১৪, Maternity ১১২ দিন (১৬ সপ্তাহ), Annual-এর জন্য Accrual Plan।

## হিসাবটা একবার কষে নাও

৩০০ কর্মীর বছরটা কেমন দাঁড়াবে, সেটা আগে বুঝে নিলে Allocation দিতে ভুল কম হবে:

| ছুটির ধরন | জনপ্রতি | ৩০০ জনে মোট (দিন) |
| --- | --- | --- |
| Casual | ১০ | ৩,০০০ |
| Sick | ১৪ | ৪,২০০ |
| Annual (Accrual) | ~২০ | ~৬,০০০ |
| Festival | ১১ | ৩,৩০০ |

দিনগুলো একসাথে নেওয়া যাবে না — প্রোডাকশন ঠিক রাখতে Department-ভিত্তিক কতজন একসাথে ছুটিতে থাকতে পারবে, সেটাও আজ ঠিক করে রাখো। Odoo-র **Overview** ক্যালেন্ডার পরে এটা দেখতে সাহায্য করবে।
