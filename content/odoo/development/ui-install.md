**গল্প:** রূপসী ফ্যাশনে ডকুমেন্ট ম্যানেজমেন্ট দরকার। এটা Odoo-র নিজস্ব অ্যাপ — তাই করিম ভাইকে টার্মিনালে হাত দিতে হবে না, Apps মেনু থেকেই ইনস্টল হয়ে যাবে।

## কখন এই পদ্ধতি

মডিউলটা **ইতিমধ্যে Odoo সিস্টেমে থাকা ডিফল্ট অ্যাপগুলোর একটা** হলে — কোডিং বা সার্ভার অ্যাক্সেস ছাড়াই ইনস্টল হয়।

## ধাপগুলো

1. Odoo অ্যাকাউন্টে **Administrator** হিসেবে লগইন করো
2. মেইন ড্যাশবোর্ড থেকে **Apps** মেনুতে ক্লিক করো
3. সার্চ বারে মডিউল/অ্যাডঅনের নাম লিখে সার্চ করো
   - সার্চ ফিল্টার থেকে **"Apps"** লেখাটা কেটে দিলে টেকনিক্যাল মডিউলগুলোও দেখা যাবে
4. মডিউল খুঁজে পেলে নিচের **Activate / Install** বাটনে ক্লিক করো

## হাতে-কলমে: Documents অ্যাপ

1. **Apps → Documents** → Activate
2. ইনস্টলের পর বাঁ দিকের মেনুতে **Documents** দেখা যাবে
3. **Settings → Documents**-এ গিয়ে ওয়ার্কস্পেস/ফোল্ডার সাজাও ([Document Management](/odoo/general-settings/documents) পেজে বিস্তারিত)

একইভাবে Sales, Inventory, Invoicing-ও ইনস্টল করা যায়।

## টিপস

| কাজ | খেয়াল রাখো |
| --- | --- |
| Administrator লাগবে | সাধারণ ইউজার Apps ইনস্টল করতে পারে না |
| "Apps" ফিল্টার | টেকনিক্যাল মডিউল দেখতে ফিল্টার সরাও |
| Odoo Online | এই পদ্ধতি Online-এও কাজ করে — সার্ভার লাগে না |
| Uninstall | ডেটা হারাতে পারে, আগে ব্যাকআপ |
