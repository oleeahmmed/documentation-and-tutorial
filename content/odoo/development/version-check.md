**গল্প:** করিম ভাই শুনেছেন, অনেকে ভুল ভার্সনের মডিউল দিয়ে পুরো Odoo অচল করে ফেলেছেন। তাই রূপসী ফ্যাশনের নিয়ম — **ব্যাকআপ ছাড়া কোনো কাস্টম মডিউল নয়**, আর ভার্সন না মিললে ইনস্টল নয়।

## নিজের Odoo ভার্সন দেখা

- **Settings** পেজের নিচের দিকে **About** — ভার্সন লেখা আছে
- অথবা টার্মিনালে:

```bash
cd ~/my-odoo
source venv/bin/activate
python3 odoo/odoo-bin --version
```

## মডিউলের ভার্সন চেক

মডিউল ফোল্ডারের `__manifest__.py` খুলে দেখো:

```python
{
    'name': 'Low Stock Report',
    'version': '18.0.1.0.0',
    'depends': ['base', 'stock'],
    'installable': True,
}
```

`version`-এর প্রথম অংশ (**18.0**) তোমার Odoo-র major version-এর সাথে মিলতে হবে — 16/17/18। `depends`-এর মডিউলগুলো আগে ইনস্টল থাকতে হবে।

## ইনস্টলের আগে চেকলিস্ট

| চেক | কেন |
| --- | --- |
| ডাটাবেস ব্যাকআপ | ভুল হলে ফিরে আসা যায় ([Database](/odoo/configuration/database)) |
| filestore ব্যাকআপ | আপলোড করা ছবি/ফাইলও থাকে |
| ভার্সন মিল | 18-এর Odoo-তে 16-এর মডিউল চলবে না |
| depends ইনস্টলড | না থাকলে মডিউল লোড হবে না |
| টেস্ট ডাটাবেসে আগে | প্রোডাকশন নিরাপদ থাকে |

## Online / Odoo.sh-এ সীমা

| প্ল্যাটফর্ম | কাস্টম মডিউল |
| --- | --- |
| **Odoo Online** | সার্ভার ফাইল নেই — শুধু Apps Store-এর ইনস্টলযোগ্য অ্যাপ |
| **Odoo.sh** | GitHub repo-তে মডিউল রাখো, প্ল্যাটফর্ম নিজে ডিপ্লয়/আপডেট করে |
| **নিজের সার্ভার** | তিনটা পদ্ধতিই খোলা ([UI](/odoo/development/ui-install), [custom_addons](/odoo/development/custom-addon), [CLI](/odoo/development/cli-install)) |
