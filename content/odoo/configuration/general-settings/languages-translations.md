**ডিফল্ট সেটিংস** — **Settings → Translations** সাধারণত শুরু থেকেই থাকে।

**গল্প:** নারায়ণগঞ্জের কর্মীরা বাংলায় কাজ করতে চায়, কিন্তু UK-র বায়ার *Styles & Threads*-কে কোটেশন যাবে ইংরেজিতে। একই Odoo-তে দুটোই সম্ভব — প্রত্যেকে নিজের ভাষা বেছে নেবে।

## ভাষা চালু করা

1. **Settings → Translations → Languages**
2. **Add Languages** চাপো
3. **বাংলা / Bengali (bn)** আর **English (en)** বেছে নাও
4. দুটোতেই **Active** টিক আছে কিনা দেখো
5. **Save**

## প্রতিটা ইউজারের ভাষা

1. avatar/নাম → **Preferences**
2. **Language** → নাদিয়া/রফিকের জন্য বাংলা, বায়ার-কমিউনিকেশনের জন্য ইংরেজি
3. **Save**

## Translations মেনু

| অপশন | কাজ |
| --- | --- |
| Application Terms → Translated Terms | মেনু/লেবেলের অনুবাদ দেখা ও বদলানো |
| Load a Translation | নতুন ভাষার অনুবাদ ফাইল লোড |
| Export / Import | নিজের লেখা (মডিউল/প্রোডাক্ট নাম) অনুবাদ করতে |

রূপসী ফ্যাশনের প্রোডাক্টের নাম দুই ভাষায় রাখতে চাইলে প্রোডাক্টের নাম-ফিল্ডে ভাষা বদলে লিখতে হয়, অথবা term translation ব্যবহার করতে হয়।

## টিপস

- কিছু কমিউনিটি মডিউলের বাংলা অনুবাদ অসম্পূর্ণ থাকতে পারে — আংশিক ইংরেজি দেখা স্বাভাবিক
- ভাষা বদলানোর পর পেজ রিফ্রেশ করো
