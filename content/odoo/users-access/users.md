**গল্প:** নাদিয়া আজ থেকে Odoo-তে কোটেশন বানাবে। করিম ভাই তার জন্য একটা ইউজার বানাবেন — আলাদা লগইন, আলাদা পাসওয়ার্ড। করিমের পাসওয়ার্ড নাদিয়াকে দেওয়ার দরকার নেই।

## নতুন ইউজার বানানো

**Settings → Users & Companies → Users → New**

| ফিল্ড | নাদিয়ার জন্য |
| --- | --- |
| Name | Nadia Akter |
| Email / Login | nadia@ruposhi.com |
| Company | Rupashi Fashion Ltd. |
| Access Rights | Sales → **User** |

1. উপরের ফিল্ডগুলো দাও
2. **Access Rights** ট্যাবে গিয়ে অ্যাপ বেছে নাও (বিস্তারিত [Groups](/odoo/users-access/groups) পেজে)
3. **Save** — মেইল সার্ভার ঠিক থাকলে নাদিয়ার ইমেইলে অ্যাক্টিভেশন/পাসওয়ার্ড সেট করার লিংক যায়
4. লিংক না গেলে: ওই ইউজারের **Action** মেনু → **Send Password Reset Instructions**

> **Login = Email** কলামের মান। তাই ইমেইল ভুল লিখলে ওই ইউজার ঢুকতেই পারবে না।

## পাসওয়ার্ড রিসেট

| কে করবে | কীভাবে |
| --- | --- |
| ইউজার নিজে | লগইন পেজে **Reset Password** → ইমেইলে লিংক |
| অ্যাডমিন | Users → ইউজার → Action → Send Password Reset Instructions |
| ইমেইল নেই | ইউজার ফর্মে সরাসরি পাসওয়ার্ড সেট (শুধু দরকারে) |

## হাতে-কলমে যাচাই

1. নাদিয়ার ইমেইল দিয়ে **ইনকগনিটো উইন্ডোতে** লগইন করো
2. দেখো — Sales মেনু আছে, Invoicing নেই
3. ভুল কিছু থাকলে মূল অ্যাকাউন্টে ফিরে Groups/Access Rights ঠিক করো

## Active / Inactive ইউজার

কর্মী চলে গেলে **ডিলিট করো না** — তার বানানো অর্ডার/ইনভয়েস ইতিহাসে থাকা দরকার।

1. Users তালিকায় ওই ইউজার খোলো
2. **Action → Archive**
3. আর্কাইভ হওয়া ইউজার আর লগইন করতে পারবে না; রেকর্ড অক্ষত থাকবে
4. ফিরিয়ে আনতে ফিল্টার **Archived** → Action → **Unarchive**

| কাজ | কেন |
| --- | --- |
| Archive, delete নয় | ইনভয়েস/অর্ডারের "Created by" ভাঙবে না |
| এক্স-employee-এর পাসওয়ার্ড | আর্কাইভের পাশাপাশি পাসওয়ার্ড বদলে দাও |
| Portal এক্সেস | বায়ারের কন্টাক্ট থেকে আলাদাভাবে Revoke করতে হবে |
