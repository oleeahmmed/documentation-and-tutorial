**গল্প:** করিম ভাই আউটলেটটাকে আলাদা কোম্পানি করতে চান — **Rupashi Retail Ltd.**, আলাদা ভ্যাট নম্বর আর হিসাব। কিন্তু Odoo একটাই, একই সার্ভার। শিপন শুধু Retail দেখবে, সুমন দুটোই।

## কোম্পানি বানানো

1. **Settings → Users & Companies → Companies → New**
2. পূরণ করো: Name, Address, Country, **Tax ID/VAT**, Currency, Logo
3. Save — এরপর টপবারের কোম্পানি সিলেক্টরে দুইটাই আসবে

## ইউজারকে কোম্পানি দেওয়া

Users → ইউজার → **Access Rights** ট্যাব:

| ফিল্ড | কাজ |
| --- | --- |
| **Allowed Companies** | কোন কোন কোম্পানির ডেটা দেখতে পারবে (একাধিক বাছা যায়) |
| **Default Company** | লগইনের সময় ডিফল্ট কোনটা |

| ইউজার | Allowed Companies |
| --- | --- |
| করিম | Fashion + Retail |
| সুমন | Fashion + Retail |
| শিপন | **শুধু Retail** |
| নাদিয়া, রফিক | Fashion only |

## হাতে-কলমে যাচাই

1. শিপন দিয়ে লগইন → টপবারে কোম্পানি সিলেক্ট করো → শুধু **Retail** আছে
2. Retail-এ একটা সেলস অর্ডার বানাও
3. কোম্পানি বদলে Fashion বাছার চেষ্টা → নেই
4. সুমন দিয়ে লগইন → সিলেক্টরে দুইটাই, "All companies" দিয়ে একসাথে দেখা যায়

## ডেটা কীভাবে আলাদা থাকে

| জিনিস | নিয়ম |
| --- | --- |
| Records (অর্ডার, ইনভয়েস) | প্রতিটার একটা **Company** ফিল্ড থাকে — অন্য কোম্পানির ইউজার দেখে না |
| Accounting | পুরোপুরি আলাদা — দুই কোম্পানির লেজার মেলে না |
| Products/Contacts | Company ফাঁকা রাখলে **সবাই শেয়ার করে**; নির্দিষ্ট করলে শুধু সেই কোম্পানি |
| Warehouses | কোম্পানিভিত্তিক — Retail-এর আউটলেট স্টক আলাদা |

> দুই কোম্পানির মধ্যে কেনাবেচা লাগলে **inter-company rules** সেট করতে হয় — শুরুতে আলাদা রাখাই সহজ।

## টিপস

| ভুল | ঠিক |
