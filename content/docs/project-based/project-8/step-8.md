## লক্ষ্য

মাহিনের হাতে জব ডেসক্রিপশন ও স্কোরিং-নিয়মের ফাইল — যেখান থেকে স্কোর আর শর্টলিস্ট ঠিক করবে।

## ফাইল বানাও

```bash
cat > knowledge/job_description.txt << 'EOF'
## পদ: Backend Developer (Django)

### আবশ্যিক শর্ত (Must-have)
- কমপক্ষে ২ বছরের Python/Django অভিজ্ঞতা
- REST API ডেভেলপমেন্টের অভিজ্ঞতা
- SQL ডাটাবেজ (PostgreSQL/MySQL) নিয়ে কাজ করার অভিজ্ঞতা

### ভালো থাকলে প্লাস পয়েন্ট (Nice-to-have)
- Celery, Redis নিয়ে অভিজ্ঞতা
- AWS/Cloud ডিপ্লয়মেন্ট অভিজ্ঞতা
- কম্পিউটার সায়েন্স বা সমমানের ডিগ্রি

### স্কোরিং নির্দেশিকা
- আবশ্যিক শর্তগুলোর কোনো একটা পূরণ না হলে fit_score যতই হোক shortlisted = false
- সব আবশ্যিক শর্ত পূরণ হলে এবং fit_score ৭০+ হলে shortlisted = true
EOF
```

> **Windows-এ heredoc চলবে না** — এডিটরে `knowledge/job_description.txt` বানিয়ে একই লেখা বসাও।

## এই ফাইল কেন গুরুত্বপূর্ণ

| এখানে যা আছে | মাহিন কী করবে |
| --- | --- |
| Must-have তিনটা | একটাও না মিললে শর্টলিস্ট করবে না, স্কোর যতই হোক |
| Nice-to-have | স্কোর বাড়াতে সাহায্য করবে, বাধ্যতামূলক নয় |
| স্কোরিং নির্দেশিকা | ৭০+ আর must-have — দুটোই সত্যি হলে তবেই শর্টলিস্ট |

> **নিয়ম:** এখানে যা নেই, মাহিন সেটা ধরে নেবে না। নতুন পদে নিয়োগ দিলে এই ফাইলটা সেই পদে বদলাও — কোড বদলাতে হবে না।

> **ন্যায্যতার কথা:** স্কোর শুধু পদের সাথে সম্পর্কিত যোগ্যতা দেখে হবে — বয়স, লিঙ্গ, ধর্ম, জাতি, ছবি বা ঠিকানা দিয়ে নয়। HR-এ AI ব্যবহারের সময় চূড়ান্ত সিদ্ধান্ত মানুষ নেবে; এজেন্ট শুধু শর্টলিস্ট সাজিয়ে দেবে।

> **Embedding দরকার:** CrewAI knowledge ডিফল্টে OpenAI embedding ব্যবহার করে। OpenAI key ছাড়া শুধু Groq/Gemini দিয়ে চালালে এখানে এরর আসতে পারে — ধাপ ১৩-এ OpenAI key বসাও বা প্রথমে knowledge বাদ দিয়ে flow দেখো।

## সমস্যা হলে

| সমস্যা | সমাধান |
| --- | --- |
| ফাইল নেই | `ls knowledge` দিয়ে যাচাই করো |
| knowledge খুঁজছে না | `crew.py`-তে `file_paths=["job_description.txt"]` মিলাও |
| সবাই শর্টলিস্ট হচ্ছে | must-have শর্ত আর স্কোরিং নির্দেশিকা আরও স্পষ্ট লেখো |
| embedding এরর | OpenAI key দাও |
