## লক্ষ্য

মিতুর হাতে Blastify-র সার্ভিস/প্রাইসিং তথ্য — যেখান থেকে পিচ নেবে।

## ফাইল বানাও

```bash
cat > knowledge/blastify_pitch.txt << 'EOF'
## Blastify কী করে
Blastify একটা SMS মার্কেটিং ও বাল্ক মেসেজিং প্ল্যাটফর্ম, ছোট-মাঝারি ব্যবসার জন্য।

## যেসব সমস্যার সমাধান করে
- কাস্টমারকে প্রমোশন/অফার জানাতে ইমেইল ওপেন রেট কম, SMS ওপেন রেট ৯৮%+
- অ্যাপয়েন্টমেন্ট রিমাইন্ডার, অর্ডার আপডেট স্বয়ংক্রিয়ভাবে পাঠানো যায়
- মাল্টি-টেন্যান্ট সিস্টেম, এজেন্সি/রিসেলারদের জন্য উপযুক্ত

## মূল্য
- স্টার্টার প্যাকেজ ছোট ব্যবসার জন্য, কোনো সেটআপ ফি নেই
- ব্যবহার অনুযায়ী ক্রেডিট কেনা যায়, মাসিক কমিটমেন্ট লাগে না

## CTA (Call To Action)
- ১৫ মিনিটের ফ্রি ডেমো কলের অফার
EOF
```

> **Windows-এ heredoc চলবে না** — এডিটরে `knowledge/blastify_pitch.txt` বানিয়ে একই লেখা বসাও।

## এই ফাইল কেন গুরুত্বপূর্ণ

| এখানে যা আছে | মিতু কী করবে |
| --- | --- |
| সার্ভিসের সংজ্ঞা | ইমেইলের প্রথম লাইনে লিডের সমস্যার সাথে মিলিয়ে বলবে |
| সমাধানের তালিকা | লিডের পেইন পয়েন্টের সাথে সবচেয়ে কাছেরটা বাছবে |
| দামের নীতি | "সেটআপ ফি নেই, মাসিক কমিটমেন্ট নেই" — ভরসা দেওয়ার তথ্য |
| CTA | ইমেইল শেষে একটাই স্পষ্ট কল: ১৫ মিনিটের ফ্রি ডেমো |

> **নিয়ম:** এখানে যা নেই, মিতু সেটা প্রতিশ্রুতি দেবে না। নতুন অফার/দাম যোগ হলে এই ফাইল আপডেট করো — কোড বদলাতে হবে না।

> **Embedding দরকার:** CrewAI knowledge ডিফল্টে OpenAI embedding ব্যবহার করে। OpenAI key ছাড়া শুধু Groq/Gemini দিয়ে চালালে এখানে এরর আসতে পারে — ধাপ ১৩-এ OpenAI key বসাও বা প্রথমে knowledge বাদ দিয়ে flow দেখো।

## সমস্যা হলে

| সমস্যা | সমাধান |
| --- | --- |
| ফাইল নেই | `ls knowledge` দিয়ে যাচাই করো |
| knowledge খুঁজছে না | `crew.py`-তে `file_paths=["blastify_pitch.txt"]` মিলাও |
| embedding এরর | OpenAI key দাও |
