## লক্ষ্য

Facebook Page-এ সরাসরি AI Customer Support চালু করা।

## এই ফেজে যা থাকবে

- Meta Developer App তৈরি।
- Facebook Page ও Messenger Webhook Integration।
- Incoming Message গ্রহণ।
- Message Processing ও AI Response।
- Messenger-এ উত্তর পাঠানো।
- Webhook Verification।
- Duplicate Message ও Failed Request Handling।

> প্রথমে Facebook Messenger-এ চালু করাই ভালো। এতে বাংলাদেশের অনলাইন শপের একটি বাস্তব Customer Support Channel পাওয়া যাবে।
