## লক্ষ্য

ব্যবসার মালিক ও সাপোর্ট কর্মীরা যেন AI-এর কাজ নিয়ন্ত্রণ করতে পারে।

## এই ফেজে যা থাকবে

- Customer Conversation Inbox।
- Ticket Management।
- AI Response Preview।
- Human Takeover।
- Agent Activity Log।
- Knowledge Base Management।
- Agent Enable / Disable।
- Support Analytics ও Reports।

> এই Dashboard-টি React দিয়ে তৈরি করা যাবে। Django REST Framework Backend হিসেবে কাজ করবে।

## কোন কনসেপ্ট শিখবে

`Agent Monitoring`, `Human-in-the-loop`
