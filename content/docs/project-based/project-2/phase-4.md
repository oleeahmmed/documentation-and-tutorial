## লক্ষ্য

AI যেন ব্যবসার ERP থেকে বাস্তব তথ্য বের করতে পারে।

## এই ফেজে যা থাকবে

- Customer Lookup Tool.
- Order Status Tool.
- Payment Verification Tool.
- Courier Tracking Tool.
- Product Availability Tool.
- Return Request Tool.

**উদাহরণ:** কাস্টমার অর্ডার নম্বর দিলে AI Django API থেকে অর্ডারের তথ্য বের করবে।

## কোন কনসেপ্ট শিখবে

`Tools`, `Reasoning`, `Context`
