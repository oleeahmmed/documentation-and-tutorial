## গল্প

তুমি একটা **অনলাইন শপ চালাও**। প্রতিদিন অর্ডার এলে কাস্টমারকে কনফার্মেশন মেইল, পেমেন্ট রসিদ, কুরিয়ার ট্র্যাকিং লিংক — সব আলাদা করে পাঠাতে হয়। তার উপর যারা কার্টে পণ্য রেখে কেনা ভুলে যায় (Abandoned Cart), তাদের ফিরিয়ে আনতে রিমাইন্ডার লাগে। একটা মানুষ দিয়ে এসব ট্র্যাক রাখা প্রায় অসম্ভব — আর কাস্টমারও "আমার অর্ডার কোথায়" জানতে চেয়ে সাপোর্টে মেইল করে।

এই সেকশনের প্রজেক্টে একটা CrewAI এজেন্ট টিম বানানো হবে, যে:

- অর্ডার এলে **কনফার্মেশন আর পেমেন্ট রসিদ** ইমেইলে পাঠাবে
- কুরিয়ার আপডেটের সাথে **ট্র্যাকিং লিংক** শেয়ার করবে
- কার্টে পণ্য রেখে কেনা না হলে **Abandoned Cart রিমাইন্ডার** পাঠাবে

## পরিকল্পিত এজেন্ট

| ভূমিকা | কাজ |
| --- | --- |
| **অর্ডার নোটিফায়ার** | অর্ডার কনফার্মেশন ও রসিদ মেইল বানাবে |
| **ট্র্যাকিং আপডেটার** | কুরিয়ার স্ট্যাটাস দেখে ট্র্যাকিং লিংকসহ আপডেট পাঠাবে |
| **কার্ট রিকভারি** | Abandoned cart ধরা পড়লে রিমাইন্ডার মেইল পাঠাবে |

> অর্ডার সোর্স (WooCommerce/Sheets/CSV) আর কুরিয়ার API কোনটা হবে — সেটা টিউটোরিয়ালে ঠিক হবে। এখন শুধু সেকশন প্রস্তুত রাখা হচ্ছে।

## কারা ব্যবহার করবে

- অনলাইন শপ — অর্ডার কমিউনিকেশন অটোমেশন
- ড্রপশিপিং বিজনেস — ট্র্যাকিং আপডেট
- ছোট ব্র্যান্ড — কার্ট রিকভারি দিয়ে সেলস বাড়ানো
