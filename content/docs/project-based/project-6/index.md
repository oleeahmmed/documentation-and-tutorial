## গল্প

তুমি একটা **কনসাল্টিং ফার্মের অপারেশনস টিমে**। প্রতিদিন ক্লায়েন্টরা মেইল করে — "আগামী সপ্তাহে কি একটা কল দেওয়া যাবে?", "মঙ্গলবার বিকেলে ফাঁকা আছেন?"। প্রতিবার কেউ একজন ক্যালেন্ডার খুলে ফাঁকা স্লট খোঁজে, রিপ্লাই লেখে, কনফার্ম হলে মিটিং লিংক বানিয়ে ইনভাইট পাঠায়। ব্যস্ত ডাক্তার, কোচ আর এক্সিকিউটিভদের ক্ষেত্রে এই ব্যাক-অ্যান্ড-ফর্থ আরও বেশি — একটা মিটিং ফিক্স করতে ৫-৬টা মেইল চলে যায়।

এই সেকশনের প্রজেক্টে একটা CrewAI এজেন্ট টিম বানানো হবে, যে:

- ক্লায়েন্টের মেইল থেকে মিটিংয়ের **আগ্ৰহ আর সময়-সূচি** বুঝে নেবে
- ইউজারের **Google Calendar** চেক করে ফাঁকা সময় বের করবে
- ক্লায়েন্টকে ফাঁকা স্লট জানিয়ে **কনফার্মেশন** নেবে
- কনফার্ম হলে **মিটিং লিংকসহ ক্যালেন্ডার ইনভাইট** পাঠাবে

## পরিকল্পিত এজেন্ট

| ভূমিকা | কাজ |
| --- | --- |
| **ইনটেন্ট রিডার** | মেইল পড়ে মিটিং চাওয়ার ইচ্ছা, পছন্দের দিন/সময়, সময়অঞ্চল বের করবে |
| **স্লট ফাইন্ডার** | Google Calendar API দেখে ফাঁকা স্লট বেছে নেবে |
| **ইনভাইট কোঅর্ডিনেটর** | কনফার্ম হলে মিটিং লিংক + ইনভাইট পাঠিয়ে ক্যালেন্ডারে ইভেন্ট বসাবে |

> Agent-দের নাম-পরিচয় আর কাজের ভাষা টিউটোরিয়ালের সাথে ঠিক হবে। এখন শুধু সেকশন প্রস্তুত রাখা হচ্ছে।

## কারা ব্যবহার করবে

- কনসালটেন্ট ও এজেন্সি — ক্লায়েন্ট কল শিডিউলিং
- ডাক্তার/ক্লিনিক — অ্যাপয়েন্টমেন্ট বুকিং
- কোচ/মেন্টর — সেশন শিডিউলিং
- ব্যস্ত এক্সিকিউটিভ — মিটিং ডেলিগেশন
