## লক্ষ্য

একটা নতুন ফোল্ডার বানিয়ে তার ভেতরে ঢোকা — এই ফোল্ডারেই পুরো প্রজেক্ট, venv আর এজেন্টদের ফাইল থাকবে।

## কমান্ড

```bash
mkdir blastify_support_agent
cd blastify_support_agent
```

`mkdir` মানে নতুন ফোল্ডার বানানো, `cd` মানে সেই ফোল্ডারের ভেতরে ঢোকা। এই ফোল্ডারই হবে তোমার পুরো প্রজেক্টের "অফিস" — এর ভেতরেই সব ফাইল থাকবে, আর এখানেই রাফি-নাদিয়া-সাকিব কাজ করবে।

## ঠিকঠাক হলো কিনা দেখো

```bash
pwd
```

Mac/Linux/Git Bash-এ পথের শেষে `blastify_support_agent` দেখাবে। Windows PowerShell-এ `Get-Location`, CMD-তে `cd` লিখলেও পথ দেখায়।

> ফোল্ডারের নামে **স্পেস দিও না** — `blastify support agent` লিখলে পরে কমান্ডে ঝামেলা হয়। ছোট হাতের অক্ষর আর আন্ডারস্কোর (`_`) নিরাপদ।

## সমস্যা হলে

| সমস্যা | সমাধান |
| --- | --- |
| `File exists` | ফোল্ডার আগেই আছে — `cd blastify_support_agent` দিয়ে ঢুকে কাজ চালাও |
| `Permission denied` | এমন জায়গায় ফোল্ডার বানাও যেখানে লেখার অধিকার আছে (যেমন Documents বা home) |
| `cd` কাজ করছে না | নামের বানান দেখো; `ls` (Windows: `dir`) দিয়ে পাশের ফোল্ডারগুলো দেখো |
