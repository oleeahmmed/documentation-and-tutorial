## লক্ষ্য

পুরো টিম একবার চালানো আর আউটপুট দেখা।

## কমান্ড

```bash
crewai install
crewai run
```

`crewai install` কমান্ডটা আমি নিজে চালিয়ে দেখেছি — এটা `uv` দিয়ে প্রজেক্টের নিজস্ব পরিবেশ বানিয়ে সব লাইব্রেরি ইনস্টল করে দেয়। তারপর `crewai run` চালালে টার্মিনালে দেখবে:

1. **রাফি (Classifier)** ইমেইলটা পড়ছে, ক্যাটাগরি বের করছে
2. **নাদিয়া (Researcher)** রাফির ফলাফল দেখে নিয়ে, নিজের নিয়মের খাতা ঘেঁটে দেখছে কোথায় উত্তর আছে
3. **সাকিব (Writer)** দুজনের কাজ দেখে নিয়ে ফাইনাল রিপ্লাই লিখছে, Subject + Body সহ — প্রয়োজনে `escalate_to_human` কল করছে

শেষে টার্মিনালে পুরো রিপ্লাইটা প্রিন্ট হবে — ঠিক যেন তিনজন কর্মচারী একের পর এক কাজ করে তোমাকে ফাইনাল রেজাল্ট দিলো।

> **প্রথম রানে সময় লাগবে** — embedding তৈরি আর LLM কলে কয়েক মিনিট লাগতে পারে। `verbose=True` থাকায় টার্মিনালে প্রতিটা এজেন্টের কাজ স্ক্রল হতে দেখবে।

## চালানোর আগে একবার দেখে নাও

| জিনিস | ঠিক আছে কিনা |
| --- | --- |
| `agents.yaml` | ৩টা এজেন্ট, key-এর নাম `classifier_agent` ইত্যাদি |
| `tasks.yaml` | context চেইন classify → research → draft |
| `knowledge/faq_policy.txt` | তিনটা সেকশন |
| `tools/custom_tool.py` | `EscalationTool` |
| `crew.py` | নাদিয়ার knowledge, সাকিবের tool |
| `main.py` | `customer_email` input |
| `.env` | `OPENAI_API_KEY` |

## তুমি এখন কী বানালে?

একটা সত্যিকারের **৩ জনের ভার্চুয়াল টিম** (রাফি, নাদিয়া, সাকিব), যার:

- **পার্মানেন্ট নির্দেশনা** আছে (`agents.yaml`, `tasks.yaml`) — চাইলে যেকোনো সময় এডিট করে আচরণ বদলাতে পারো
- **নলেজ বেস** আছে (`knowledge/faq_policy.txt`) — নাদিয়ার নিয়মের খাতা, আরও তথ্য যোগ করলেই এজেন্ট আরও স্মার্ট হবে
- **স্কিল/টুল** আছে (`escalate_to_human`) — চাইলে সাকিবকে আরও টুল যোগ করতে পারো (যেমন: সরাসরি ইমেইল পাঠানোর টুল)
- **স্কিল রেজিস্টার** আছে (`skills.md`) — কে কী করতে পারে তার তালিকা, এক নজরে দেখার জন্য
- **মেমোরি** আছে (`memory=True`) — প্রতিবার রান করলে আগের কথা মনে রাখে

এখন তুমি নিজে `sample_email`-এর জায়গায় নিজের কোম্পানির আসল কাস্টমার ইমেইল বসিয়ে টেস্ট করে দেখতে পারো। কোনো ধাপে এরর পেলে, এরর মেসেজটা দাও — একসাথে ঠিক করে ফেলি।

## সমস্যা হলে

| সমস্যা | সমাধান |
| --- | --- |
| `uv` খুঁজে পাচ্ছে না | `pip install uv` অথবা `crewai install` আবার চালাও |
| খালি/ভাঙা আউটপুট | `.env` key, `faq_policy.txt`-এর নাম, YAML ইনডেন্টেশন দেখো |
| knowledge embedding এরর | OpenAI key বসাও, বা কিছুক্ষণ `memory=False` করে টেস্ট করো |
| `escalations.json` তৈরি হয়নি | টেস্ট ইমেইলে FAQ-তে নেই এমন প্রশ্ন দাও |
| একই রিপ্লাই বারবার | cache/memory; নতুন ইমেইল দিয়ে চালাও |
