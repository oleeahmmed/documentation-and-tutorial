**গল্প:** বগুড়ার রাত ১০:১৫। ডেভেলপার **Olee Ahmmed** আজ বসেছেন একটা বিশেষ লক্ষ্য নিয়ে — এমন বাস্তবসম্মত সমস্যা (Job Posts) বিশ্লেষণ করবেন, যেগুলো Upwork-এর বিদেশি ক্লায়েন্টদের পাশাপাশি বাংলাদেশের WordPress/Custom ই-কমার্স, HR আর সফটওয়্যার কোম্পানির আসল সমস্যা সমাধান করে।

এমন একটা প্রজেক্ট বেছে নিলে **এক ঢিলে দুই পাখি** — Upwork পোর্টফোলিওতে হেভিওয়েট প্রজেক্ট, আর বাংলাদেশে SaaS/সার্ভিস হিসেবে বিক্রি করা যায়।

## কেন Project Based শিখবেন

| শুধু টিউটোরিয়াল | Project Based |
| --- | --- |
| কনসেপ্ট শেখা হয় | কনসেপ্ট + আসল ক্লায়েন্টের সমস্যা |
| ডেমো শেষে ভুলে যাওয়ার ঝুঁকি | পোর্টফোলিওতে দেখানোর মতো কাজ |
| "কী বানাবো" প্রশ্ন থেকে যায় | ক্লায়েন্ট পোস্ট থেকেই স্কোপ পরিষ্কার |

## ২০টা পোস্ট — চার ভাগে

| ভাগ | সংখ্যা | পোস্ট |
| --- | --- | --- |
| ই-কমার্স অটোমেশন | ৫ | ফ্রড ডিটেকশন, ইনবক্স সেলস, রিফান্ড, পেমেন্ট মিলানো, SEO |
| HR ও কর্পোরেট/গার্মেন্টস | ৫ | সিভি স্ক্রিনিং, অ্যাটেনডেন্স/OT, লিভ অ্যাসিস্ট্যান্ট, লেবার ল, Churn |
| সফটওয়্যার কোম্পানি | ৪ | SRS/Jira, GitHub রিভিউ, সাপোর্ট টিকিট, B2B লিড |
| ফিন্যান্স, লিগ্যাল ও অন্যান্য | ৬ | ইনভয়েস অডিট, কন্ট্রাক্ট রিস্ক, ক্লিনিক সামারি, কনটেন্ট, রিয়েল এস্টেট, মিটিং মিনিটস |

সব পোস্ট ক্লায়েন্ট, বাজেট আর সমস্যাসহ: **[২০টা ক্লায়েন্ট জব পোস্ট](/docs/project-based/job-posts)**।

## কোনটা বেছে নেবেন

```text
বাংলাদেশে সহজে ক্লায়েন্ট পাওয়া যায়? → ই-কমার্স (Option A)
বড় বাজেট + কর্পোরেট সেক্টর?        → HR (Option B)
নিজের ফার্ম/এজেন্সির টুল?            → সফটওয়্যার (Option C)
```

তিন অপশনের তুলনা আর সিদ্ধান্তের ফ্রেমওয়ার্ক: **[Decision Matrix](/docs/project-based/project-1/decision-matrix)**।
