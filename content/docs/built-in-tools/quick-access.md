## এক নজরে — Quick Access

সবচেয়ে বেশি ব্যবহৃত টুলগুলো:

| দরকার হলে | ব্যবহার করো |
| --- | --- |
| ফাইল পড়া | `FileReadTool` |
| ইন্টারনেট সার্চ | `SerperDevTool` |
| ওয়েবপেজ পড়া | `ScrapeWebsiteTool` |
| কাস্টম knowledge-এ সার্চ | `RagTool` |
| ছবি তৈরি | `DallETool` |
| AWS S3 অ্যাক্সেস | `S3ReaderTool` |

এই টেবিলটাই তোমার দ্রুত রেফারেন্স — নতুন প্রজেক্ট শুরু করার সময় এখান থেকেই বেছে নিতে পারো। প্রতিটা টুলের বিস্তারিত উদাহরণ পেতে সাইডবারের সংশ্লিষ্ট বিভাগে যাও।
