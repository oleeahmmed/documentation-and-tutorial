## ধাপ ৯: Skills

### বাস্তব গল্প (রূপসী ফ্যাশন)

সুমনের ডেস্কের পাশে একটা আলমারি আছে। সেই আলমারিতে বিভিন্ন বিশেষ-কৌশলের বই রাখা — একটা বইয়ে লেখা “উলের কাপড়ের ডিজাইন কৌশল”, আরেকটায় “সুতির কাপড়ের ডিজাইন কৌশল”, আরেকটায় “সিল্কের ডিজাইন কৌশল”।

এখানে knowledge-এর মতো এই বইগুলো “সবসময়” লাগে না — শুধু যখন সুমন **নির্দিষ্ট করে উলের কাপড় নিয়ে কাজ করছে**, তখনই তার ওই একটা নির্দিষ্ট বই বের করে পড়া দরকার, বাকি বইগুলো তখন তার দরকার নেই।

করিম ভাই বলেছিলেন:

> “সুমন, আলমারিতে অনেক বই আছে। যখন যে কাপড় নিয়ে কাজ করবে, শুধু সেই কাপড়ের বইটাই বের করে পড়বে। সব বই একসাথে পড়ার দরকার নেই।”

### CrewAI-তে এই একই জিনিস

এই “প্রয়োজন-অনুযায়ী বেছে পড়া বই”-এর ধারণাটাকেই CrewAI-তে বলা হয় **Skills** — প্রতিটা স্কিল একটা ফোল্ডারে, `SKILL.md` ফাইলে লেখা, আর CrewAI নিজে থেকেই ঠিক করে কোন স্কিলটা এই মুহূর্তে প্রাসঙ্গিক।

**Knowledge বনাম Skills:** Knowledge হলো তথ্য — সবসময় হাতের কাছে। Skills হলো পদ্ধতি/কৌশল — শুধু প্রয়োজনমতো খোলা হয়।

### ফোল্ডার বানাও

```text
rupashi_fashion/
├── .env
├── crew_project.py
└── skills/
    └── woolen-design/
        └── SKILL.md
```

### `skills/woolen-design/SKILL.md`

```markdown
---
name: woolen-design
description: উলের কাপড়ের ডিজাইনের সময় ব্যবহার করো — বুনন ও লেয়ারিং সংক্রান্ত নিয়ম।
---

# উলের কাপড়ের ডিজাইন কৌশল

- উলের কাপড়ে মোটা বুনন সবসময় প্রথমে প্রাধান্য দিতে হয়।
- লেয়ারিং করলে ভেতরের লেয়ার পাতলা রাখতে হয়, নইলে পোশাক ভারী লাগবে।
- উলের রঙ গাঢ় হলে বোতাম বা অ্যাকসেসরি হালকা রঙের বেছে নিতে হয়।
```

ফোল্ডারের নাম (`woolen-design`) অবশ্যই `SKILL.md`-এর ভেতরের `name`-এর সাথে মিলতে হবে — এটা CrewAI-এর নিয়ম। চাইলে CLI দিয়েও স্কিল বানানো যায়: `crewai create skill woolen-design`।

### কোড (সুমনকে স্কিল দিলাম)

```python
designer = Agent(
    role="ফ্যাশন ডিজাইনার",
    goal="ট্রেন্ড দেখে আকর্ষণীয় নতুন ডিজাইন আইডিয়া তৈরি করা",
    backstory="তুমি সুমন, ছোটবেলা থেকেই আঁকাআঁকি করো।",
    allow_delegation=True,
    knowledge_sources=[brand_guide],
    skills=["./skills"]   # 👈 নতুন — পুরো স্কিল-ফোল্ডার CrewAI নিজেই discover করবে
)
```

### বাস্তবে কী ঘটে — ধাপে ধাপে

CrewAI এটা দুই ধাপে করে:

**ধাপ ১ — Discovery:** কাজ শুরুর আগে CrewAI শুধু `SKILL.md`-এর `description`-টুকু পড়ে দেখে (পুরো বডি না):

```text
woolen-design → description: উলের কাপড়ের ডিজাইনের সময় ব্যবহার করো — বুনন ও লেয়ারিং সংক্রান্ত নিয়ম।
```

**ধাপ ২ — Activation:** এবার Task-এর description দেখে (“উলের ওভারকোট ডিজাইন বানাও” — যেহেতু রফিকের দেওয়া তথ্যে “উলের ওভারকোট” আছে), CrewAI বুঝে নেয় এই স্কিলটাই প্রাসঙ্গিক, তাই পুরো বডি prompt-এ ঢুকিয়ে দেয়:

```text
তোমার কাজ: ডিজাইন আইডিয়া বানাও।

[Activated Skill: woolen-design]
# উলের কাপড়ের ডিজাইন কৌশল
- উলের কাপড়ে মোটা বুনন সবসময় প্রথমে প্রাধান্য দিতে হয়।
- লেয়ারিং করলে ভেতরের লেয়ার পাতলা রাখতে হয়।
- উলের রঙ গাঢ় হলে বোতাম/অ্যাকসেসরি হালকা রঙের বেছে নিতে হয়।
```

সুমন এবার যা রিটার্ন করে:

```text
১. খাকি-বাদামি উলের ওভারকোট — মোটা বুননে, হালকা রঙের কাঠের বোতাম সহ
২. পাতলা পেস্টেল সোয়েটারের উপর গাঢ় উলের শাল (লেয়ারিং কৌশল মেনে)
```

লক্ষ্য করো — সুমন এবার “মোটা বুনন” আর “হালকা বোতাম” এর কথা উল্লেখ করেছে, যা সরাসরি স্কিল-ফাইল থেকে এসেছে। যদি সুমনের কাজ সুতির কাপড় নিয়ে হতো, তাহলে এই `woolen-design` স্কিলটা একদমই ব্যবহার হতো না — CrewAI শুধু প্রাসঙ্গিক স্কিলটাই activate করে, বাকিগুলো আলমারিতেই পড়ে থাকে।
