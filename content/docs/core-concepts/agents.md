> গল্প দিয়ে CrewAI শেখার সিরিজ — প্রতিটা টপিকে আগে **রূপসী ফ্যাশনের বাস্তব গল্প**, তারপর ঠিক একই জিনিস **CrewAI-তে**। সিরিজের ভূমিকা: [Getting Started](/docs/getting-started/overview)।

## গল্পের শুরু

বগুড়ায় একজন মানুষ থাকেন। নাম **করিম ভাই**।

তিনি একটা ছোট ফ্যাশন কোম্পানি চালান। কোম্পানির নাম **রূপসী ফ্যাশন**।

কোম্পানিটা শুরু হয়েছিল মাত্র একটা ছোট্ট দোকান দিয়ে। করিম ভাই নিজেই কাপড় কিনতেন, নিজেই ডিজাইন ভাবতেন, নিজেই ফেসবুকে পোস্ট দিতেন।

কিন্তু সময়ের সাথে সাথে ব্যবসা বাড়তে লাগলো। কাস্টমার বাড়লো। অর্ডার বাড়লো। করিম ভাই বুঝতে পারলেন — তিনি একা আর সব সামলাতে পারছেন না।

একদিন রাতে বসে তিনি ভাবলেন — “আমার একটা টিম দরকার। যারা যার কাজ ভালো বোঝে, তাদের নিয়োগ দিতে হবে।”

এই চিন্তা থেকেই আমাদের গল্প শুরু।

## ধাপ ১: Agents

### বাস্তব গল্প (রূপসী ফ্যাশন)

করিম ভাই ভাবলেন, তাকে তিন ধরনের মানুষ লাগবে — একজন বাজার বোঝে, একজন ডিজাইন বোঝে, একজন লেখালেখি বোঝে।

তিনি প্রথমে বাজারে গেলেন। সেখানে তার পরিচিত **রফিক** নামের একজন ছিলেন, যিনি অনেক বছর ধরে কাপড়ের বাজার ঘুরে বেড়ান, দোকানদারদের সাথে খাতির আছে, কোন কাপড় চলছে কোনটা চলছে না — সব তার নখদর্পণে। করিম ভাই তাকে ডেকে বললেন:

> “রফিক, আমি তোমাকে একটা কাজ দিতে চাই। তোমার পদবী হবে — **বাজার গবেষক**। তোমার কাজ হবে, প্রতিটা সিজনে নতুন ফ্যাশন ট্রেন্ড খুঁজে বের করা। আমি জানি তুমি এই কাজে পারদর্শী, কারণ তুমি অনেকদিন ধরে বাজার চেনো।”

রফিক রাজি হলো।

এরপর করিম ভাই গেলেন তার পরিচিত এক তরুণের কাছে, নাম **সুমন**। সুমন ছোটবেলা থেকেই আঁকাআঁকি করতো, কাপড়ের নকশা নিয়ে তার আলাদা একটা মুগ্ধতা ছিল। করিম ভাই তাকে বললেন:

> “সুমন, তোমার পদবী হবে — **ফ্যাশন ডিজাইনার**। রফিক যে ট্রেন্ডগুলো খুঁজে আনবে, তুমি সেগুলো দেখে নতুন নতুন ডিজাইন আইডিয়া বানাবে। তুমি সৃজনশীল মানুষ, এই কাজ তোমার জন্যই।”

শেষে করিম ভাই গেলেন **নাদিয়ার** কাছে। নাদিয়া ভালো লিখতে পারেন, ফেসবুক-ইনস্টাগ্রামে কীভাবে মানুষকে আকৃষ্ট করতে হয় তিনি বোঝেন। করিম ভাই বললেন:

> “নাদিয়া, তোমার পদবী হবে — **মার্কেটিং লেখক**। সুমন যে ডিজাইনগুলো বানাবে, তুমি সেগুলো দিয়ে মানুষের মন টানা পোস্ট লিখবে।”

লক্ষ্য করো — করিম ভাই প্রত্যেককে ডাকার সময় তিনটা জিনিস স্পষ্ট করে বলেছেন:

1. তার **পদবী** কী (role)
2. তার **কাজ/লক্ষ্য** কী (goal)
3. তিনি **কেন এই কাজে ভালো** — তার পটভূমি (backstory)

এই তিনটা জিনিস না বললে, নতুন কর্মী বুঝতেই পারবে না সে কী করবে আর কেন তাকে এই কাজের জন্য বাছা হলো।

### CrewAI-তে এই একই জিনিস

CrewAI-তে প্রত্যেক কর্মীকে বলা হয় **Agent**। আর করিম ভাই যে তিনটা জিনিস বললেন, কোডেও ঠিক সেই তিনটা জিনিস দিতে হয়:

- `role` → পদবী
- `goal` → লক্ষ্য
- `backstory` → পটভূমি

### কোড (নতুন প্রজেক্ট শুরু)

একবার প্যাকেজগুলো ইনস্টল করে নাও:

```bash
pip install crewai python-dotenv
```

তারপর একটা ফোল্ডার বানাও:

```text
rupashi_fashion/
├── .env
└── crew_project.py
```

`.env`-এ:

```bash
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxx
```

`crew_project.py`-তে:

```python
import os
from dotenv import load_dotenv
from crewai import Agent

load_dotenv()

researcher = Agent(
    role="বাজার গবেষক",
    goal="প্রতিটা সিজনে নতুন ফ্যাশন ট্রেন্ড খুঁজে বের করা",
    backstory="তুমি রফিক, অনেক বছর ধরে কাপড়ের বাজার ঘুরে বেড়াও, দোকানদারদের "
               "সাথে ভালো যোগাযোগ আছে, তাই নতুন ট্রেন্ড সবার আগে ধরতে পারো।"
)

designer = Agent(
    role="ফ্যাশন ডিজাইনার",
    goal="ট্রেন্ড দেখে আকর্ষণীয় নতুন ডিজাইন আইডিয়া তৈরি করা",
    backstory="তুমি সুমন, ছোটবেলা থেকেই আঁকাআঁকি করো, কাপড়ের নকশার প্রতি "
               "তোমার আলাদা মুগ্ধতা আছে।"
)

marketer = Agent(
    role="মার্কেটিং লেখক",
    goal="ডিজাইন আইডিয়া দিয়ে কাস্টমারদের আকৃষ্ট করার মতো পোস্ট লেখা",
    backstory="তুমি নাদিয়া, তুমি জানো কীভাবে ফেসবুক-ইনস্টাগ্রামে মানুষের "
               "মন টানা যায়।"
)
```

### এখন কী অবস্থা

এই মুহূর্তে করিম ভাই তিনজনকে নিয়োগ দিয়েছেন ঠিকই, কিন্তু **কাউকে এখনো কোনো আসল কাজ দেননি**। তিনজনই দাঁড়িয়ে আছে, তৈরি, কিন্তু হাতে কোনো অ্যাসাইনমেন্ট নেই।

কোডেও একই অবস্থা — `researcher`, `designer`, `marketer` তিনটা অবজেক্ট তৈরি হয়েছে, কিন্তু এদের এখনো কোনো `Task` দেওয়া হয়নি। এই Agent গুলো এই মুহূর্তে চালালেও কিছু হবে না, কারণ কী করতে হবে সেটাই বলা হয়নি।
