## ধাপ ১০: LLMs

### বাস্তব গল্প (রূপসী ফ্যাশন)

করিম ভাই একদিন খেয়াল করলেন — রফিক, সুমন, নাদিয়া তিনজনেরই কাজের ধরন একদম আলাদা।

রফিকের কাজ হলো শুধু তথ্য খুঁজে বের করা — এখানে বেশি “চিন্তাশক্তি” লাগে না, দ্রুত আর সস্তায় কাজ হলেই চলে। কিন্তু সুমনের কাজ হলো সৃজনশীল ডিজাইন বানানো — এখানে একটু বেশি মেধাবী, গভীরভাবে চিন্তা করতে পারা একজন মানুষ লাগে।

করিম ভাই ভাবলেন:

> “রফিকের জন্য একজন সাধারণ, দ্রুত কাজ করা কর্মী হলেই চলবে — বেতনও কম দিতে হবে। কিন্তু সুমনের জন্য একজন অভিজ্ঞ, উচ্চ-মেধাবী ডিজাইনার লাগবে, যার বেতন বেশি হলেও সমস্যা নেই, কারণ তার কাজের মান অনেক গুরুত্বপূর্ণ।”

অর্থাৎ — **প্রতিটা কর্মীর “মস্তিষ্কের ক্ষমতা” আলাদা হতে পারে, কাজের ধরন অনুযায়ী।**

### CrewAI-তে এই একই জিনিস

একটা Agent-এর “মস্তিষ্ক” মানে হলো তার পেছনে কোন **LLM** (ভাষা-মডেল) কাজ করছে। CrewAI-তে প্রতিটা Agent-কে আলাদা আলাদা LLM দেওয়া যায়, `LLM` ক্লাস দিয়ে।

### কোড (নতুন অংশ)

```python
from crewai import LLM

fast_llm = LLM(
    model="gpt-4o-mini",   # দ্রুত, সস্তা — রফিকের জন্য যথেষ্ট
    temperature=0.3         # কম randomness — তথ্যভিত্তিক কাজে স্থিরতা দরকার
)

creative_llm = LLM(
    model="gpt-4o",         # বেশি শক্তিশালী — সুমনের সৃজনশীল কাজের জন্য
    temperature=0.8         # বেশি randomness — সৃজনশীলতা বাড়ে
)
```

এবার এই “মস্তিষ্ক”গুলো সংশ্লিষ্ট কর্মীদের বসিয়ে দিই:

```python
researcher = Agent(
    role="বাজার গবেষক",
    goal="প্রতিটা সিজনে নতুন ফ্যাশন ট্রেন্ড খুঁজে বের করা",
    backstory="তুমি রফিক, অনেক বছর ধরে কাপড়ের বাজার ঘুরে বেড়াও।",
    tools=[price_checker],
    llm=fast_llm   # 👈 নতুন যোগ হলো
)

designer = Agent(
    role="ফ্যাশন ডিজাইনার",
    goal="ট্রেন্ড দেখে আকর্ষণীয় নতুন ডিজাইন আইডিয়া তৈরি করা",
    backstory="তুমি সুমন, ছোটবেলা থেকেই আঁকাআঁকি করো।",
    allow_delegation=True,
    knowledge_sources=[brand_guide],
    skills=["./skills"],
    llm=creative_llm   # 👈 নতুন যোগ হলো
)
```

### বাস্তবে কী ঘটে

আগে (কোনো `llm` না দিলে) CrewAI ডিফল্টভাবে একটা মডেল (সাধারণত `gpt-4o`, আপনার সেটআপ অনুযায়ী) সবার জন্য ব্যবহার করতো। এখন:

```text
রফিকের কাজের খরচ ও সময় কম লাগবে (gpt-4o-mini, কম temperature
→ স্থির, পুনরাবৃত্তিযোগ্য উত্তর)

সুমনের কাজে একটু বেশি সময়/খরচ লাগবে, কিন্তু ডিজাইনে বৈচিত্র্য ও
সৃজনশীলতা বেশি আসবে (gpt-4o, বেশি temperature)
```

তুমি চাইলে Claude, Gemini বা লোকাল মডেলও বসাতে পারো, যেমন `LLM(model="anthropic/claude-sonnet-4-5")` — CrewAI প্রায় সব প্রোভাইডার সাপোর্ট করে, শুধু মডেলের নামটা বদলে দিলেই হয়।
