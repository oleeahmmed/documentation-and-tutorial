CrewAI হলো একটা পাইথন ফ্রেমওয়ার্ক, যা দিয়ে তুমি একাধিক AI "কর্মী" (Agent) একসাথে কাজ করিয়ে একটা জটিল কাজ সমাধান করাতে পারো — ঠিক যেমন একটা টিমের প্রতিটা সদস্য নিজের নির্দিষ্ট দায়িত্ব পালন করে, মিলিয়ে একটা বড় কাজ শেষ করে।

**CrewAI দিয়ে কী করা যায়:**

- একটা বিষয়ে গবেষণা করিয়ে, তার উপর ভিত্তি করে লেখা তৈরি করানো
- একাধিক AI Agent-কে নিজেদের মধ্যে কাজ ভাগ করে দেওয়া
- ইমেইল, ডকুমেন্ট, ডেটাবেস — যেকোনো উৎস থেকে তথ্য নিয়ে স্বয়ংক্রিয়ভাবে প্রতিবেদন বানানো

**শুরু করার আগে যা লাগবে:**

- Python সংস্করণ **3.10 থেকে 3.13**-এর মধ্যে হতে হবে (3.14 এখনো সাপোর্ট করে না)
- একটা LLM প্রোভাইডারের API key (যেমন OpenAI-এর `OPENAI_API_KEY`)

নিজের Python ভার্সন চেক করো:

```bash
python3 --version
```

এখন [ইনস্টলেশন](/docs/getting-started/installation)-এ যাওয়া যাক।
