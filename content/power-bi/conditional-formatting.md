## গল্প

Matrix টেবিলে সংখ্যার সাগরে করিম ভাই কোন ঘরটা খারাপ সেটা খুঁজে পান না। সমাধান সহজ — যেই মাসে বিক্রি কম, সেই ঘর লাল; বেশি হলে সবুজ। কোনো মেজার লিখতে হবে না, Power BI-র **Conditional Formatting** দিয়েই হবে।

## হাতে-কলমে: Background Color

1. Matrix ভিজ্যুয়ালটা সিলেক্ট করো
2. **Visualizations** প্যানেলের **Values** সেকশনে `Total Revenue`-এর পাশের ছোট ড্রপডাউনে ক্লিক করো
3. **Conditional formatting → Background color**
4. ডান দিকের প্যানেলে:
   - **Format style:** Color scale
   - **Minimum:** লাল, **Maximum:** সবুজ (ডিফল্ট রঙ বদলাতে পারো)
   - **Apply to:** Values only
5. **OK**

Matrix-এর প্রতিটা ঘরে এখন রঙের ছায়া — কম অঙ্ক বেশি লাল, বেশি অঙ্ক বেশি সবুজ। এক নজরে দুর্বল মাসগুলো চোখে পড়ে।

## আরও দুটো স্টাইল

### Data bars

একই মেনু থেকে **Data bars** বেছে নিয়ে সবুজ বার দাও — ঘরের ভেতরে ছোট বার-চার্টের মতো দেখাবে, সংখ্যাও থাকবে।

### Rules দিয়ে নির্দিষ্ট সীমা

"৫০,০০০ টাকার নিচে হলেই লাল" — এভাবে চাইলে:

1. Conditional formatting → Background color
2. **Format style:** Rules
3. **If value is** → less than → `50000` → লাল রং
4. **Add** দিয়ে আরেকটা নিয়ম: greater than or equal to `50000` → সবুজ

Color scale-এ সবচেয়ে ছোট ঘরও লাল হয়, সবচেয়ে বড় ঘরও সবুজ — একেবারে খারাপ কেউ না থাকলেও। নিয়ম (Rules) দিলে আসল সীমার ভিত্তিতে রঙ ঠিক হয়।

## আউটপুট কেমন দেখাবে

```text
Salesperson | January | February | March
রফিক       | 82,000  | 45,000   | 91,000
সুমন        | 38,000  | 61,000   | 54,000
নাদিয়া      | 95,000  | 88,000   | 40,000
```

৪৫,০০০ আর ৩৮,০০০-এর ঘর লালচে, ৯০,০০০-এর ঘর গাঢ় সবুজ — এই দৃশ্যটাই করিম ভাই চেয়েছিলেন।

## বাস্তবে কী ঘটে

- রং আসলে **ডেটার মানের ওপর** নির্ভর করে, স্থির নয় — Slicer-এ অঞ্চল বদলালে রঙের ছায়াও বদলাবে
- Conditional formatting শুধু **ওই ভিজ্যুয়ালের** সাজসজ্জা, ডেটা বা মেজার বদলায় না
- একই নিয়ম Card, Bar Chart-এও দেওয়া যায় — নিয়ম প্রতিটা ভিজ্যুয়ালের জন্য আলাদা করে সেট করতে হয়
- Matrix-এ row/column subtotal-এ রং আলাদা করে বন্ধ করা যায় (Apply to: Values only)

## সমস্যা হলে

| সমস্যা | সমাধান |
| --- | --- |
| Values-এর পাশে ড্রপডাউন নেই | ভিজ্যুয়াল সিলেক্ট করা আছে কিনা দেখো — আগে Matrix-এ ক্লিক করো |
| সব ঘর একই রঙ | Minimum/Maximum দুটোই একই রঙে সেট হয়ে গেছে — আলাদা করো |
| রঙ দেখা যাচ্ছে না | **Format → Cell elements → Background color** চালু আছে কিনা দেখো |
| Rules কাজ করছে না | সংখ্যার বদলে টেক্সট হিসেবে মান আছে কিনা দেখো (Formatting pane-এ "Number" বেছে নাও) |
| Print-এ রঙ আসছে না | File → Options → Report settings → **Print visuals with colors** চালু করো |
