## গল্প

করিম ভাই রিপোর্টটা শুধু দেখবেন না, ছুঁতেও চান। দুইটা দাবি:

1. "প্রথমে বছর দেখব, কোন বছরে কম — সেটায় ক্লিক করলে মাস ধরে দেখব"
2. "একটা বাটনে শুধু শীতকালীন পণ্য, আরেকটা বাটনে সব পণ্য — দুই ভিউ-এর মধ্যে বদলাব"

দুটোই কোনো কোড ছাড়া হবে — **Drill-down** আর **Bookmarks**।

## ১০.১ — Drill Down

### লেভেল বসানো

1. Line Chart বা Bar Chart সিলেক্ট করো
2. **X-axis**-এ প্রথমে `DateTable[Year]`, তারপর `DateTable[Quarter]`, তারপর `DateTable[Month]` বসাও
3. ভিজ্যুয়ালের উপরে ছোট **তীর (drill) আইকন** আসবে — চার্ট এখন Year লেভেলে দেখাচ্ছে

> `DateTable`-কে Mark as date table করা থাকলে Power BI নিজেই Year → Quarter → Month হায়ারার্কি বানিয়ে দেয়। না থাকলে কলামগুলো হাতে সাজালেও কাজ হবে।

### ডুব দেওয়া

| আইকন | কাজ |
| --- | --- |
| **↓ একক তীর** | Drill down mode — একটা বারে (যেমন 2026) ক্লিক করলে শুধু সেই বছরের Quarter দেখাবে |
| **↓↑ দুই তীর** | Expand — সব বছরের নিচে Quarter-ও একসাথে দেখাবে |
| **↑ উপরে তীর** | এক লেভেল উপরে ফেরা |
| **বাতিল আইকন** | Drill mode বন্ধ, আবার পূর্ণ ভিউ |

Matrix-এ ড্রিল আরও সহজ — Row হায়ারার্কির পাশে `+` চিহ্নে ক্লিক করলে ভেতরে ঢোকে।

### Drill Through (অ্যাডভান্সড)

আলাদা একটা পেজে গিয়ে নির্দিষ্ট একটা ক্যাটাগরির বিস্তারিত দেখতে চাইলে **Drill through** ব্যবহার হয় — ভিজ্যুয়ালের `...` → Drill through → পেজ বেছে নাও। শুরুতে এটা লাগবে না, জানা থাকল ভালো।

## ১০.২ — Bookmarks: দুই ভিউ, দুই বাটন

### বুকমার্ক বানানো

1. `Category` স্লাইসার থেকে **শীতকালীন** সিলেক্ট করো
2. **View → Bookmarks** প্যানেল খোলো → **Add**
3. নতুন বুকমার্কে ডাবল-ক্লিক করে নাম দাও `Winter View`
4. স্লাইসার থেকে সিলেক্ট ক্লিয়ার করে সব দেখাও
5. আবার **Add** → নাম দাও `All Products`

এখন দুটো স্ন্যাপশট সেভ আছে — কোন স্লাইসার সিলেক্ট করা, কোন ভিজ্যুয়াল দেখা যাচ্ছে, সব।

> বুকমার্ক তৈরি করার সময় প্যানেলের `...` → **Data** চেক করা থাকে কিনা দেখো — এটাই ফিল্টার-অবস্থা সেভ করে। এটা বন্ধ থাকলে শুধু ভিজ্যুয়ালের চেহারা সেভ হবে, স্লাইসারের সিলেকশন নয়।

### বাটন বসানো

1. **Insert → Buttons → Blank** (বা Text) বেছে নাও
2. ক্যানভাসে বসিয়ে টেক্সট বদলাও: `শীতকালীন`
3. বাটন সিলেক্ট করে **Format → Button → Action** → **Type: Bookmark** → Bookmark: `Winter View`
4. একইভাবে দ্বিতীয় বাটন: `সব পণ্য` → `All Products`

এখন রিপোর্ট চালু করে বাটনে ক্লিক করলেই পুরো পেজ সেই ভিউতে চলে যাবে।

## বাস্তবে কী ঘটে

- Drill-down **দেখার** অবস্থা বদলায়, ডেটা বা মেজার বদলায় না — উপরে ফিরে এলে আগের ভিউ ফিরে আসে
- বুকমার্কে স্লাইসারের সিলেকশন সেভ হয়, তাই "All Products" বুকমার্কে ফিরলে আগের ফিল্টারও ফিরে আসে
- একটা বুকমার্ক **Update** না করে আবার Add করলে পুরোনোটা অক্ষত থাকে — ভুল হলে ডিলিট করে নতুন করো
- বুকমার্ক মোবাইল অ্যাপেও কাজ করে — করিম ভাই ফোন থেকেই দুই ভিউ বদলাতে পারবেন
- Slicer-এর সিলেকশন বুকমার্কে সেভ হয়, কিন্তু **অন্য পেজের বুকমার্ক** আলাদা; পেজ-নেভিগেশন বাটনও একই পদ্ধতিতে বানানো যায়

## সমস্যা হলে

| সমস্যা | সমাধান |
| --- | --- |
| Drill আইকন দেখাচ্ছে না | X-axis-এ একাধিক লেভেল বসাও; Year/Quarter/Month ক্রমে আছে কিনা দেখো |
| ড্রিল করলে সব চার্ট বদলে যাচ্ছে | স্বাভাবিক — একটাতে ড্রিল করলে সম্পর্কিত সব ভিজ্যুয়াল ফিল্টার হয় |
| বাটনে ক্লিক করলে কিছু হয় না | Action → Type = Bookmark সেট করেছ কিনা, সঠিক নাম বেছেছ কিনা দেখো |
| Bookmark ফিল্টার ফিরিয়ে আনছে না | Bookmarks প্যানেলের `...` → Data চালু করো, তারপর বুকমার্ক **Update** করো |
| বাটন ক্যানভাসে দেখা যাচ্ছে না | Insert → Buttons থেকে নতুন বাটন বানাও; পুরোনো ভিজ্যুয়ালের পেছনে লুকিয়ে থাকতে পারে |
