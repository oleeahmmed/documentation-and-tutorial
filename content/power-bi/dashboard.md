## গল্প

আলাদা আলাদা ভিজ্যুয়াল হয়েছে, কিন্তু ছড়ানো-ছিটানো অবস্থায় সেগুলো রিপোর্ট নয় — শুধু চার্টের ভিড়। করিম ভাই চান এক পাতা খুললেই পুরো ব্যবসার ছবি। এখন সাজানোর পালা।

## হাতে-কলমে: পেজ সাজানো

1. নিচের **Page 1**-এ ডাবল-ক্লিক করে নাম দাও `Sales Overview`
2. **Insert → Text box** দিয়ে উপরে লিখো: `রূপসী ফ্যাশন — বিক্রয় ড্যাশবোর্ড`
3. ফন্ট সাইজ ২০-২৪, বোল্ড করো
4. এবার ভিজ্যুয়ালগুলো সাজাও:

```text
┌──────────────────────────────────────────────┐
│  রূপসী ফ্যাশন — বিক্রয় ড্যাশবোর্ড            │
├───────────────────────┬──────────────────────┤
│  Card: Total Revenue  │  Card: Total Profit  │
├───────────────────────┴──────────────────────┤
│  Line Chart: মাস অনুযায়ী বিক্রির ট্রেন্ড        │
├───────────────────────┬──────────────────────┤
│  Bar Chart: অঞ্চল      │  Map: ভৌগোলিক বিশ্লেষণ │
├───────────────────────┴──────────────────────┤
│  Matrix: বিক্রয়কর্মী × মাস                    │
├──────────────────────────────────────────────┤
│  Slicer: Region        Slicer: Category      │
└──────────────────────────────────────────────┘
```

### সাজানোর টুল

- ভিজ্যুয়াল সিলেক্ট করে **Format → Align** দিয়ে বাঁয়ে/ডানে/উপরে মিলাও
- **View → Snap to grid** আর **Show gridlines** চালু করো — টানা সাইজে বসানো সহজ হবে
- একই আকারের দুটো কার্ড বানাতে একটা কপি করে (Ctrl+C, Ctrl+V) মান বদলাও — সাইজ এক থাকবে
- **View → Lock objects** দিয়ে ভুলে সরানো আটকাও (সাজানো শেষে)

### থিম বদলানো

**View → Themes** থেকে রেডিমেড থিম বেছে নাও, অথবা **Customize current theme** দিয়ে রং ঠিক করো। একটা নিয়ম মেনে চলো — পুরো রিপোর্টে **২-৩টার বেশি মূল রং নয়**। এলোমেলো রং করিম ভাইকে বিভ্রান্ত করবে।

## Design নীতি

| নীতি | কারণ |
| --- | --- |
| সবচেয়ে গুরুত্বপূর্ণ সংখ্যা (Card) সবার উপরে | মানুষ প্রথমে উপরের বাঁ দিক পড়ে |
| সম্পর্কিত ভিজ্যুয়াল পাশাপাশি | চোখ এক জায়গায় রেখে তুলনা করা যায় |
| Slicer নিচে বা বাঁ পাশে | খুঁজে পেতে সহজ, মূল চার্ট ঢাকে না |
| এক পেজে ৫–৭টার বেশি ভিজ্যুয়াল নয় | বেশি হলে মনোযোগ ভাগ হয়ে যায় |
| 3D চার্ট এড়াও | দেখতে চটকদার, পড়তে কঠিন |
| শিরোনাম-লেবেল স্পষ্ট | "Total Revenue" নয়, "মোট বিক্রি (৳)" — করিম ভাইয়ের ভাষায় |

## Mobile Layout

করিম ভাই ফোনে দেখবেন — তাই আলাদা করে ফোনের লেআউট ঠিক করতে হবে:

1. **View → Mobile layout**
2. ড্রপডাউন থেকে `Sales Overview` পেজ বেছে নাও
3. ফোনের স্ক্রিনে ভিজ্যুয়ালগুলো টেনে সাজাও — উপরে Card, তারপর Line Chart, সবশেষে Matrix
4. উপরে **Back to desktop layout**

ডেস্কটপ আর মোবাইল — দুটো লেআউট আলাদা করে সেভ হয়, একটা বদলালে অন্যটা নষ্ট হয় না।

## ফাইল সেভ

**File → Save as** → নাম দাও `rupashi_dashboard.pbix`

`.pbix` ফাইলটাই তোমার পুরো কাজ — ডেটা, মডেল, মেজার, ভিজ্যুয়াল সব এর ভেতরে। এই ফাইলটা পরে Service-এ পাবলিশ করব (পর্ব ১১)।

## বাস্তবে কী ঘটে

- ভিজ্যুয়াল ক্যানভাসের সাথে স্কেল হয় না — পেজ সাইজ বদলালে আবার সাজাতে হতে পারে (Format page → Canvas settings)
- Slicer-এর ফিল্টার শুধু **এই পেজে** কাজ করে; অন্য পেজেও চাইলে **Sync slicers** (View → Sync slicers) চালু করো
- ভিজ্যুয়াল বেশি হলে পেজ ধীরে লোড হয় — Matrix আর Map সবচেয়ে ভারী
- থিম বদলালে সব ভিজ্যুয়ালের রং একসাথে বদলায়, কিন্তু Conditional Formatting-এর রং অক্ষত থাকে

## সমস্যা হলে

| সমস্যা | সমাধান |
| --- | --- |
| ভিজ্যুয়াল একটার ওপর আরেকটা | Format → Align; Snap to grid চালু করো |
| ভিজ্যুয়াল টেনে সরাতে পারছি না | Lock objects চালু আছে কিনা দেখো |
| পেজের বাইরে চলে যাচ্ছে | Canvas settings → Fit to page, বা ভিজ্যুয়াল রিসাইজ করো |
| টেক্সট বক্স দেখা যাচ্ছে না | Insert → Text box, তারপর ক্যানভাসে ক্লিক করে লেখো |
| Mobile layout খালি | প্রতিটা ভিজ্যুয়াল মোবাইল ক্যানভাসে টেনে বসাতে হবে — অটো কপি হয় না |
