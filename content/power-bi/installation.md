## গল্প

করিম ভাই ভেবেছিলেন Power BI মানে হয়তো আরেকটা ওয়েবসাইট, যেখানে Excel আপলোড করে টেবিল দেখবে। আসলে Power BI তিনটা আলাদা অংশ নিয়ে কাজ করে — একটা কম্পিউটারের অ্যাপ, একটা ওয়েবসাইট, আর একটা মোবাইল অ্যাপ। কোনটা কখন লাগে জানলে পুরো সিস্টেমটা পরিষ্কার হয়ে যায়।

## তিনটা অংশ

| অংশ | কাজ | কোথায় পাবে |
| --- | --- | --- |
| **Power BI Desktop** | যেখানে রিপোর্ট বানাবে — ডেটা আনা, মডেল, ভিজ্যুয়াল সব এখানে | তোমার কম্পিউটারে ইনস্টল করা অ্যাপ |
| **Power BI Service** | ওয়েবসাইট — রিপোর্ট পাবলিশ করে করিম ভাইয়ের সাথে শেয়ার | `app.powerbi.com` |
| **Power BI Mobile** | মোবাইলে রিপোর্ট দেখার অ্যাপ | Play Store / App Store |

মনে রাখো: **বানানোর কাজ Desktop-এ, দেখানোর কাজ Service-এ।** Desktop বন্ধ করলেও Service-এ পাবলিশ করা রিপোর্ট চলে।

## হাতে-কলমে: ইনস্টল

1. ব্রাউজারে [powerbi.microsoft.com/desktop](https://powerbi.microsoft.com/desktop) খুলো
2. **Download free** ক্লিক করো (Microsoft Store থেকেও পাওয়া যায়)
3. ডাউনলোড হওয়া `PBIDesktopSetup_x64.exe` চালিয়ে **Next → Next → Install**
4. ইনস্টল শেষে **Launch** — Power BI Desktop খুলবে

> Power BI Desktop **শুধু Windows-এর জন্য**। Mac-এ Desktop সংস্করণ নেই — সেখানে শুধু Service (ব্রাউজার) দিয়ে কাজ করা যায়। তাই এই টিউটোরিয়ালে Windows ধরে নেওয়া হয়েছে।

## প্রথমবার খোলার সময়

প্রথম স্ক্রিনে Microsoft অ্যাকাউন্ট দিয়ে সাইন-ইন করতে বলবে। এখনই করতে পারো, অথবা **Already have Power BI? → Maybe later** ক্লিক করে শুধু Desktop দিয়ে শুরু করতে পারো — ইনস্টল আর ডেটা আনার জন্য সাইন-ইন লাগে না। পাবলিশ করার সময় (পর্ব ১১) লাগবে।

সাইন-ইন না করলে উপরে হলুদ একটা বার দেখাবে — এটা স্বাভাবিক, উপেক্ষা করো।

## ইন্টারফেস চেনা

চারটা জায়গা চিনলেই যথেষ্ট:

| জায়গা | কী আছে |
| --- | --- |
| বাম পাশের তিন আইকন | **Report** (ভিজ্যুয়াল সাজানো), **Table** (ডেটা টেবিলে দেখা), **Model** (টেবিল-সংযোগ) |
| ডান পাশের **Visualizations** প্যানেল | সব চার্টের আইকন, Field-এ ডেটা টেনে বসানোর জায়গা |
| ডান পাশের **Data** প্যানেল | টেবিল আর কলামের তালিকা |
| মাঝের সাদা **Canvas** | যেখানে ভিজ্যুয়াল বসাবে — এটাই রিপোর্ট পেজ |

নিচে বাম দিকে **Page 1** — একটা রিপোর্টে একাধিক পেজ থাকতে পারে।

## ফ্রি বনাম Pro

- **Desktop** সবসময় ফ্রি — বানানো, সেভ করা, `.pbix` ফাইল নিজের কম্পিউটারে রাখা
- **Service-এ শেয়ার করা, Scheduled Refresh, Row-Level Security** — এগুলোর জন্য সাধারণত **Power BI Pro** লাইসেন্স লাগে (৩০ দিনের ট্রায়াল পাওয়া যায়)
- একা নিজের জন্য চর্চা করতে Pro লাগবে না — পর্ব ১১-এ গিয়ে দরকার হলে ট্রায়াল নিতে পারবে

## সমস্যা হলে

| সমস্যা | সমাধান |
| --- | --- |
| ইনস্টলার "This app can't run on your PC" | ৬৪-বিট Windows দরকার; `x64` সেটআপ নামিয়েছ কিনা দেখো |
| Microsoft Store-এ পাওয়া যাচ্ছে না | সরাসরি ওয়েবসাইট থেকে `.exe` নামাও |
| সাইন-ইন স্ক্রিনে আটকে গেছ | **Maybe later** ক্লিক করো, পরে Service-এর সময় সাইন-ইন করব |
