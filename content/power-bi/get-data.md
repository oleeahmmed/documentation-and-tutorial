## গল্প

ফাইলটা তৈরি, এখন Power BI-কে বলতে হবে "এই ডেটা তুমি পড়ো"। Power BI-তে ডেটা আনার দরজাটার নাম **Get Data** — Excel ছাড়াও CSV, SQL ডেটাবেস, ওয়েব API, Google Analytics, এমনকি ওয়েব পেজ থেকেও ডেটা আনা যায়। আমাদের জন্য Excel-ই যথেষ্ট।

## হাতে-কলমে

1. Power BI Desktop খোলো (খালি রিপোর্ট থাকবে)
2. Home ট্যাবে **Get Data** বাটনে ক্লিক করো
3. তালিকা থেকে **Excel workbook** বেছে নিয়ে **Connect**
4. `sales_data.xlsx` ফাইলটা খুঁজে বের করে **Open** করো

এখন একটা **Navigator** উইন্ডো আসবে।

## Navigator-এ কী দেখাচ্ছে

বাম পাশে ফাইলের ভেতরের শিট/টেবিলের তালিকা — `Sales` আর `Products`।

| জায়গা | কাজ |
| --- | --- |
| বাম প্যানেলের চেকবক্স | কোন শিট আনবে বাছাই |
| ডান পাশের প্রিভিউ | ডেটা কেমন দেখতে, প্রথম সারি হেডার কি না |
| **Load** | সরাসরি ডেটা মডেলে ঢুকিয়ে দেয় |
| **Transform Data** | Power Query Editor খোলে — সেখানে পরিষ্কার করার সুযোগ |

`Sales`-এর চেকবক্সে ✔ দাও। `Products` এখনই লাগবে না — পর্ব ৫-এ আলাদা করে আনব (যদিও একবারে দুটোই আনা যায়)।

## Load নাকি Transform Data?

| অবস্থা | কী করবে |
| --- | --- |
| ডেটা পরিষ্কার, টাইপ ঠিক | **Load** |
| ডুপ্লিকেট, খালি ঘর, ভুল টাইপ | **Transform Data** |

আমরা ইচ্ছে করে ডেটা নোংরা করেছি (পর্ব ২), তাই এবার **Transform Data** ক্লিক করো। এতে Power Query Editor খুলবে — পরের পর্বের পুরো কাজটাই সেখানে।

> **আগে Load করে ফেলেছ?** সমস্যা নেই। Home → **Transform data** ক্লিক করলেই একই এডিটর খুলবে।

## ভেতরে কী ঘটছে

Power BI এখনই ডেটা কপি করেনি — বরং একটা **কোয়েরি** বানিয়েছে: "এই ফাইলের এই শিট পড়ো, তারপর এই ধাপগুলো করো"। কোয়েরিটা সেভ থাকে, তাই পরে ফাইল আপডেট হলে রিফ্রেশ করলেই নতুন ডেটা চলে আসে। এজন্য Power BI-র রিপোর্ট "লাইভ" — প্রতিবার নতুন করে টেবিল বানাতে হয় না।

## সমস্যা হলে

| সমস্যা | সমাধান |
| --- | --- |
| ফাইল খুঁজে পাচ্ছি না | ফাইলটা যেখানে সেভ করেছ সেখান থেকে বেছে নাও; OneDrive-এ থাকলে সিঙ্ক শেষ কিনা দেখো |
| Navigator-এ শিট দেখাচ্ছে না | শিটের নাম ঠিক আছে কিনা, ফাইলটা আসল `.xlsx` কিনা (পুরোনো `.xls` হলে আলাদা কানেক্টর) দেখো |
| প্রথম সারিটা হেডার হয়নি | Transform Data-তে গিয়ে Home → **Use First Row as Headers** |
| "We couldn't find any data" | শিটে ডেটা আছে কিনা, ফাঁকা শিট বাছাই করনি কিনা দেখো |
| পরে ফাইল সরিয়ে ফেলেছি | Data source settings-এ পাথ বদলাও, নইলে রিফ্রেশ হবে না |

পরের ধাপে [Power Query Editor](/power-bi/power-query) — ডেটা পরিষ্কার করব।
