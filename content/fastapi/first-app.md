## গল্প

প্রথম কাজটা ছোট — শুধু দেখতে হবে সার্ভারটা ঠিকঠাক কথা বলে কিনা। করিম ভাই বললেন, "আগে দরজাটা খোলো, ভেতরে কী আছে পরে দেখব।"

## কোড (`main.py`)

প্রজেক্ট ফোল্ডারে `main.py` নামে ফাইল বানিয়ে লেখো:

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "রূপসী ফ্যাশনের API-তে স্বাগতম"}
```

- `FastAPI()` — পুরো অ্যাপের মূল অবজেক্ট
- `@app.get("/")` — মানে `/` ঠিকানায় GET রিকোয়েস্ট এলে নিচের ফাংশন চলবে
- ফাংশন যা `return` করছে, FastAPI সেটাকে নিজে থেকেই JSON বানিয়ে পাঠায়

## চালাও

```bash
fastapi dev main.py
```

টার্মিনালে এরকম দেখবে:

```text
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
INFO:     Started reloader process
```

`fastapi dev` মানে ডেভেলপমেন্ট মোড — ফাইল সেভ করলেই সার্ভার নিজে থেকে রিস্টার্ট হয়। প্রোডাকশনে `fastapi run main.py` ব্যবহার করবে।

## বাস্তবে কী ঘটে

ব্রাউজারে এই তিনটা ঠিকানা খুলে দেখো:

```text
http://127.0.0.1:8000/          → {"message": "রূপসী ফ্যাশনের API-তে স্বাগতম"}
http://127.0.0.1:8000/docs      → স্বয়ংক্রিয় Swagger UI (আলাদা ইনস্টলের দরকারই নেই!)
http://127.0.0.1:8000/redoc     → স্বয়ংক্রিয় Redoc ডকুমেন্টেশন
```

`/docs` পেজে ট্রাই-আউট বাটন আছে — সেখান থেকেই ব্রাউজারে বসে API টেস্ট করা যায়। কোনো পোস্টম্যান লাগে না।

## টিপস

- ফাংশনের নাম (`home`) যা-ই দাও, কাজ একই। তবে অর্থপূর্ণ নাম দিলে `/docs`-এ বোঝা সহজ হয়।
- ফাংশনে `async def` ব্যবহার করলে FastAPI আরও নমনীয়ভাবে চালাতে পারে — সেটা [Async পেজে](/fastapi/async) দেখা হবে। শুরুতে সাধারণ `def`-ই যথেষ্ট।
- সার্ভার বন্ধ করতে টার্মিনালে `Ctrl + C` চাপো।

এখন [Path Parameters](/fastapi/path-parameters)-এ যাও — URL দিয়ে নির্দিষ্ট পণ্য খোঁজা শিখব।
